# DNS — 学习方向

## 核心概念
- **DNS 层级**：根域名 → TLD（顶级域）→ 权威 DNS → 本地 DNS
- **记录类型**：A（IPv4）、AAAA（IPv6）、CNAME（别名）、MX（邮件）、TXT（文本记录）、NS（域名服务器）
- **解析过程**：递归查询 vs 迭代查询
- **TTL**：缓存时间（影响变更生效速度）
- **CDN 调度**：DNS 根据来源 IP 返回不同 IP

## 常用工具
```bash
dig example.com                # 标准 DNS 查询
dig +trace example.com         # 跟踪完整解析路径
nslookup example.com           # 简单查询
host example.com               # 快速查询
```

## 实操清单
- [ ] 购买域名后配置 DNS（阿里云/Cloudflare/Route53）
- [ ] 配置 A 记录指向服务器 IP
- [ ] 配置 CNAME 指向 CDN 域名
- [ ] 配置 MX 记录指向邮箱服务
- [ ] 配置 TXT 记录做域名验证（SSL 证书、SPF、DKIM）
- [ ] 使用 `dig +trace` 完整排查 DNS 解析链路
- [ ] 配置子域名委派（NS 记录）

## 常见场景
- 域名解析不生效 -> 排查 TTL 缓存和 DNS 传播
- 域名被劫持 -> 检查 DNS 解析结果
- 配置子域名指向不同服务器
- 切换 CDN/云厂商，修改 CNAME 记录
