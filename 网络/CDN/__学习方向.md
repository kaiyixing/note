# CDN — 学习方向

## 核心概念
- **CDN**（Content Delivery Network）：内容分发网络
- **边缘节点**：遍布各地的缓存服务器
- **回源**：边缘节点没有缓存时，向源站请求
- **预热**：提前将内容缓存到边缘节点
- **刷新**：主动清除边缘节点缓存

## 关键技术
- **DNS 调度**：根据用户 IP 返回最近的 CDN 节点 IP
- **Anycast**：多节点共享同一 IP，路由到最近节点
- **HTTPS 加速**：证书管理、TLS 握手优化
- **动态加速**（DCDN）：动态内容通过优化路由加速
- **WAF**：CDN 边缘的安全防护

## 常见场景
- 网站图片/视频加载慢 -> 上 CDN
- 海外用户访问慢 -> 全球 CDN 节点
- 源站带宽有限 -> CDN 缓存减轻回源压力
- 被 DDoS -> CDN 的 WAF + 流量清洗
