# 负载均衡 — 学习方向

## 核心分层

| 层级 | 代表 | 场景 |
|------|------|------|
| **四层**（LVS） | IPVS + Keepalived | 入口流量分发，高性能 TCP/UDP |
| **七层**（Nginx / HAProxy） | 反向代理 | HTTP/HTTPS 路由、SSL 卸载、应用层分发 |
| **DNS 负载均衡** | 多 A 记录 / CNAME | 全局流量调度，地理就近访问 |
| **云原生** | K8s Service / Ingress | 容器场景的负载均衡 |

## Nginx（重点掌握）
- 反向代理配置（`proxy_pass`）
- 负载均衡策略：轮询、权重、IP_HASH、least_conn
- 健康检查（`health_check` 或 `upstream` 被动检测）
- SSL 终止配置
- 限流（`limit_req`、`limit_conn`）
- 动静分离

## LVS
- **DR 模式**（直接路由）vs **NAT 模式** vs **TUN 模式**
- 配合 Keepalived 实现高可用（VRRP）

## HAProxy
- 四层 + 七层负载均衡
- 丰富的统计页面（`stats`）
- ACL 规则灵活路由

## 常见场景
- 多台 Web 服务器统一入口（反向代理 + 负载均衡）
- HTTPS 统一卸载（证书放在 LB 层）
- 蓝绿发布、灰度发布（权重分发）
