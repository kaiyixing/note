# Prometheus 配置文件存放位置

## 一、配置文件在 Kubernetes 中的存储方式

在 Kubernetes 中，配置文件存储在 **ConfigMap** 和 **Secret** 资源中，而不是本地文件系统。

### ConfigMap 存储位置

```bash
# 查看所有配置
kubectl get configmap -n monitoring

# 查看某个配置详情
kubectl get configmap <配置名> -n monitoring -o yaml
```

### Secret 存储位置

```bash
# 查看所有 Secret
kubectl get secret -n monitoring
```

## 二、各组件配置文件位置

### 1. Prometheus

| 配置项 | ConfigMap 名称 | 说明 |
|--------|---------------|------|
| 主配置 | `prometheus-kube-prometheus-prometheus` | 抓取规则、服务发现等 |
| 告警规则 | `prometheus-kube-prometheus-prometheus-rulefiles-0` | 35 条告警规则 |
| Alertmanager 配置 | 在主配置中指定 | 告警通知配置 |

**查看命令**:
```bash
kubectl get configmap prometheus-kube-prometheus-prometheus -n monitoring -o yaml
```

### 2. Alertmanager

| 配置项 | 存储位置 | 说明 |
|--------|---------|------|
| 告警路由 | Secret: `alertmanager-prometheus-kube-prometheus-alertmanager` | 告警接收者配置 |
| 通知渠道 | 同上 | 邮件/钉钉/Slack 等配置 |

**查看命令**:
```bash
# 解码查看
kubectl get secret alertmanager-prometheus-kube-prometheus-alertmanager -n monitoring -o yaml | grep -A 10 "alertmanager.yaml"
```

### 3. Grafana

| 配置项 | ConfigMap 名称 | 说明 |
|--------|---------------|------|
| 主配置 | `prometheus-grafana` | 数据源、插件、皮肤等 |
| Dashboard | `prometheus-grafana-config-dashboards` | 预置监控面板 |
| 数据源 | `prometheus-kube-prometheus-grafana-datasource` | Prometheus 数据源 |

**查看命令**:
```bash
kubectl get configmap prometheus-grafana -n monitoring -o yaml
```

## 三、如何修改配置

### 1. 修改 Prometheus 配置

```bash
# 方法1: 直接编辑 ConfigMap
kubectl edit configmap prometheus-kube-prometheus-prometheus -n monitoring

# 方法2: 使用 Helm 升级
helm upgrade prometheus prometheus-community/kube-prometheus-stack -n monitoring -f values.yaml
```

### 2. 修改 Alertmanager 配置

```bash
# 编辑 Alertmanager 配置
kubectl edit secret alertmanager-prometheus-kube-prometheus-alertmanager -n monitoring

# 或者通过 Helm values.yaml 配置
```

### 3. 修改 Grafana 配置

```bash
# 编辑 Grafana ConfigMap
kubectl edit configmap prometheus-grafana -n monitoring
```

## 四、配置文件内容示例

### Alertmanager 配置 (alertmanager.yaml)

```yaml
global:
  resolve_timeout: 5m
route:
  group_by: ['namespace']
  group_wait: 10s
  group_interval: 10s
  repeat_interval: 12h
  receiver: 'default'
  routes:
  - match:
      alertname: Watchdog
    receiver: 'null'
receivers:
- name: 'default'
  email_configs:
  - to: 'your-email@example.com'
    send_resolved: true
```

### Prometheus 抓取配置 (prometheus.yml)

```yaml
global:
  scrape_interval: 15s
  evaluation_interval: 15s
scrape_configs:
- job_name: 'kubernetes-nodes'
  kubernetes_sd_configs:
  - role: node
  relabel_configs:
  - action: labelmap
    regex: __meta_kubernetes_node_label_(.+)
- job_name: 'kubernetes-pods'
  kubernetes_sd_configs:
  - role: pod
- job_name: 'kubernetes-services'
  kubernetes_sd_configs:
  - role: service
```

## 五、配置持久化说明

| 组件 | 持久化方式 | 默认存储位置 |
|------|-----------|--------------|
| Prometheus | ConfigMap + TSDB | 无持久化（测试环境） |
| Alertmanager | Secret | 无持久化 |
| Grafana | ConfigMap + PVC | 无 PVC（测试环境） |
| node-exporter | 无状态 | 不需要持久化 |

> 注意：当前部署为测试环境，未配置持久化存储。如需生产环境，建议配置 PV/PVC。

## 六、常用命令汇总

```bash
# 查看所有配置
kubectl get all -n monitoring

# 查看 ConfigMap
kubectl get configmap -n monitoring

# 查看 Secret
kubectl get secret -n monitoring

# 查看 PrometheusRule (告警规则)
kubectl get prometheusrule -n monitoring

# 查看 ServiceMonitor
kubectl get servicemonitor -n monitoring

# 查看 PodMonitor
kubectl get podmonitor -n monitoring

# 查看 Alertmanager 配置
kubectl get secret alertmanager-prometheus-kube-prometheus-alertmanager -n monitoring -o jsonpath='{.data.alertmanager\.yaml}' | base64 -d

# 查看 Prometheus 告警规则
kubectl get prometheusrule -n monitoring -o jsonpath='{.items[0].spec.groups[0].rules[0]}'
```
