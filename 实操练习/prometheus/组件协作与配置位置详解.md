## 二、配置文件详细位置

### 1. 数据抓取配置 (ServiceMonitor)

**作用**: 定义要监控的目标服务

```bash
# 查看所有 ServiceMonitor
kubectl get servicemonitor -n monitoring

# 查看 node-exporter ServiceMonitor 配置
kubectl get servicemonitor prometheus-prometheus-node-exporter -n monitoring -o yaml
```

**关键配置**:
```yaml
spec:
  selector:
    matchLabels:
      app.kubernetes.io/name: prometheus-node-exporter
  endpoints:
  - port: http-metrics        # 抓取端口
    scheme: http             # 协议
```

### 2. 服务发现 (Service/Endpoints)

**作用**: 记录实际可访问的 IP:Port

```bash
# 查看所有 Endpoints
kubectl get endpoints -n monitoring

# 查看 node-exporter endpoints
kubectl get endpoints prometheus-prometheus-node-exporter -n monitoring -o yaml
```

**关键配置**:
```yaml
subsets:
- addresses:
  - ip: 192.168.233.10
    targetRef:
      kind: Node
      name: k8s-master
  - ip: 192.168.233.11
    targetRef:
      kind: Node
      name: k8s-node1
  ports:
  - port: 9100
    protocol: TCP
```

### 3. Prometheus 主配置 (Prometheus CRD)

**作用**: Prometheus 全局配置，包括抓取间隔、告警配置等

```bash
# 查看 Prometheus 配置
kubectl get prometheus -n monitoring -o yaml

# 查看具体 spec
kubectl get prometheus prometheus-kube-prometheus-prometheus -n monitoring -o jsonpath='{.spec}' | jq
```

**关键配置**:
```yaml
spec:
  scrapeInterval: 30s          # 抓取间隔
  evaluationInterval: 30s     # 告警评估间隔
  serviceMonitorSelector:
    matchLabels:
      release: prometheus      # 选择 ServiceMonitor 标签
  ruleSelector:
    matchLabels:
      release: prometheus     # 选择告警规则标签
  alerting:
    alertmanagers:
    - name: prometheus-kube-prometheus-alertmanager
      namespace: monitoring
      port: http-web
```

### 4. 告警规则配置 (PrometheusRule)

**作用**: 定义告警规则

```bash
# 查看所有告警规则
kubectl get prometheusrule -n monitoring

# 查看具体规则
kubectl get prometheusrule prometheus-kube-prometheus-k8s.rules.node -n monitoring -o yaml
```

**关键配置**:
```yaml
apiVersion: monitoring.coreos.com/v1
kind: PrometheusRule
metadata:
  labels:
    release: prometheus
spec:
  groups:
  - name: k8s.rules.node
    rules:
    - alert: NodeExporterDown
      expr: up{job="kubernetes-nodes"} == 0
      for: 10m
      labels:
        severity: critical
      annotations:
        summary: "Node Exporter down"
```

### 5. Alertmanager 配置 (Secret)

**作用**: 告警通知配置

```bash
# 查看 Alertmanager 配置
kubectl get secret alertmanager-prometheus-kube-prometheus-alertmanager -n monitoring \
  -o jsonpath='{.data.alertmanager\.yaml}' | base64 -d
```

**关键配置**:
```yaml
global:
  resolve_timeout: 5m
route:
  group_by: ['namespace']
  group_wait: 10s
  group_interval: 10s
  repeat_interval: 12h
  receiver: 'default'
receivers:
- name: 'default'
  # 通知渠道配置 (邮件/钉钉/Slack等)
```

## 四、查看抓取状态

### 1. 查看 Targets (通过 Prometheus UI)

```bash
# 端口转发访问
kubectl port-forward -n monitoring svc/prometheus-kube-prometheus-prometheus 9090:9090

# 浏览器访问: http://localhost:9090/targets
```

### 2. 查看抓取配置 (通过 kubectl)

```bash
# 查看 ServiceMonitor
kubectl get servicemonitor -n monitoring -o wide

# 查看 Endpoints
kubectl get endpoints -n monitoring

# 查看 Prometheus 配置
kubectl get prometheus -n monitoring -o yaml | grep -A 20 "serviceMonitorSelector"
```

## 五、修改抓取配置示例

### 1. 添加新的监控目标

**方式一**: 通过 ServiceMonitor (推荐)
```yaml
apiVersion: monitoring.coreos.com/v1
kind: ServiceMonitor
metadata:
  name: my-app-monitor
  namespace: monitoring
  labels:
    release: prometheus
spec:
  selector:
    matchLabels:
      app: my-app
  endpoints:
  - port: metrics
    path: /metrics
```

### 2. 修改抓取间隔

```bash
# 通过 Helm values 修改
helm upgrade prometheus prometheus-community/kube-prometheus-stack \
  -n monitoring \
  --set prometheus.scrapeInterval=15s \
  --set prometheus.evaluationInterval=15s
```
