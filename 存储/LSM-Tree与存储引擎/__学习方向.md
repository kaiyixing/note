# LSM-Tree 与存储引擎 — 学习方向

## 核心概念
- **LSM-Tree**（Log-Structured Merge-Tree）：写优化的数据结构
- **SSTable**：有序键值对文件，不可变
- **MemTable**：内存中的缓冲结构（写先写这里）
- **Compaction**：合并 SSTable 文件（减少读放大）
- **WAL**（Write-Ahead Log）：崩溃恢复保障
- **B+ Tree vs LSM-Tree**：读优化 vs 写优化的对比

## 哪些系统在用 LSM-Tree
| 系统 | 应用场景 |
|------|----------|
| **LevelDB / RocksDB** | 嵌入式 KV 存储 |
| **Cassandra / ScyllaDB** | 分布式 NoSQL |
| **HBase** | 大数据列式存储 |
| **TiKV** | 分布式 KV（TiDB 的存储层） |
| **InfluxDB** | 时序数据库 |
