# MinIO 对象存储 — 学习方向

## 核心概念
- **对象存储** vs 文件存储 vs 块存储
- **Bucket**：存储桶（类似目录）
- **Object**：对象（文件 + 元数据）
- **S3 兼容 API**：与 AWS S3 协议完全兼容
- **Erasure Coding**：纠删码，MinIO 的核心数据保护机制

## 部署与使用
```bash
# Docker 单机部署
docker run -p 9000:9000 -p 9001:9001 minio/minio server /data --console-address ":9001"

# 客户端 mc 使用
mc alias set myminio http://localhost:9000 admin admin123
mc mb myminio/my-bucket
mc cp myfile.txt myminio/my-bucket/
```

## 常见场景
- 自建图床/文件存储（替代阿里云 OSS）
- Kubernetes 中的 PVC 后端（使用 S3 协议）
- 数据库备份存储（`pg_dump` 到 MinIO）
- 大数据日志归档
