# 存储性能调优 — 学习方向

## 核心指标
- **IOPS**：每秒读写次数
- **吞吐量**：每秒数据量（MB/s）
- **延迟**：每次 IO 耗时（ms）
- **iowait**：CPU 等待 IO 的时间占比

## 排查工具
| 工具 | 用途 |
|------|------|
| `iostat -x 1` | 查看磁盘利用率、await、svctm |
| `iotop` | 查看哪个进程在大量读写 |
| `sar -d` | 历史 IO 性能记录 |
| `fio` | 磁盘性能基准测试 |
| `blktrace` | 块层 IO 追踪 |

## 调优方向
- **文件系统**：调整 `noatime`、`data=writeback`（ext4）
- **I/O 调度器**：`none`（NVMe）/ `mq-deadline`（SATA）
- **RAID 策略**：条带大小、cache 策略
- **内核参数**：`vm.dirty_ratio`、`vm.swappiness`
- **应用层**：连接池、批量写入、缓存策略

## 常见场景
- 数据库突然变慢，iowait 升高
- 磁盘读写没问题，但应用感觉慢
- 新买的 SSD 测速没达到标称值
