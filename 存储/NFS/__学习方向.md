# NFS — 学习方向

## 核心概念
- **NFS**（Network File System）：Linux 之间的网络文件共享
- **服务端**：`nfs-server`（`nfs-kernel-server`）
- **客户端**：`mount` 挂载远程目录
- **NFS 版本**：v3（广泛）vs v4（更快、更安全）
- **RPC 依赖**：`portmap` / `rpcbind`

## 配置示例

```
# 服务端 /etc/exports
/data/share 192.168.1.0/24(rw,sync,no_subtree_check)

# 客户端挂载
mount -t nfs 192.168.1.100:/data/share /mnt/share
```
