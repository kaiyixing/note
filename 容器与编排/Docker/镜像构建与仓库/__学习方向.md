# Docker 镜像构建与仓库 — 学习方向

## 核心概念
- **镜像分层**：UnionFS、每一层都是只读的
- **构建缓存**：层缓存机制（每一层有 hash）
- **多阶段构建**：构建环境与运行环境分离（减小镜像体积）
- **镜像仓库**：Docker Hub、Harbor（私有仓库）
- **镜像安全**：Trivy 漏洞扫描、签名（Docker Content Trust）

## 多阶段构建示例
```dockerfile
# 第一阶段：构建
FROM golang:1.21 AS builder
WORKDIR /app
COPY . .
RUN go build -o myapp

# 第二阶段：运行
FROM alpine:3.18
COPY --from=builder /app/myapp /myapp
CMD ["/myapp"]
```

## 常见场景
- 构建的镜像太大，推送和拉取都很慢
- 镜像构建总是从头开始，缓存没利用上
- 需要在内网环境管理私有镜像
