# Dockerfile 最佳实践 — 学习方向

## 核心原则

| 原则 | 说明 |
|------|------|
| **选择合适的基础镜像** | Alpine（小）、slim（轻量）、distroless（最小） |
| **减少层数** | `RUN` 命令用 `&&` 合并，避免每行一层 |
| **利用构建缓存** | 不变的操作放前面（apt install），常变的放后面（COPY 源码） |
| **多阶段构建** | 构建环境和运行环境分离 |
| **不要用 root** | 添加 `USER` 非 root 用户运行 |
| **健康检查** | `HEALTHCHECK` 指令 |

## 各语言推荐基础镜像

| 语言 | 推荐基础镜像 |
|------|-------------|
| Go | `golang:alpine`（构建）→ `alpine` 或 `scratch`（运行） |
| Java | `eclipse-temurin:17-jre-alpine` |
| Python | `python:3.11-slim` |
| Node | `node:20-alpine` |

## 安全最佳实践
- 不使用 `latest` 标签（指定精确版本）
- 不把密钥/密码写入镜像（用 `ARG` + 构建时变量）
- 定期扫描漏洞（Trivy / Snyk）
- 用 `COPY` 代替 `ADD`（除非需要自动解压缩）
- 加 `--no-cache`（apk）或 `--no-install-recommends`（apt）
