# Kubernetes Operator — 学习方向

## 核心概念
- **Operator**：用 K8s 原生方式管理复杂应用
- **CRD**（Custom Resource Definition）：自定义资源类型
- **Controller**：监听资源变化，调谐到期望状态
- **调谐循环**（Reconcile Loop）：Observe → Diff → Act
- **已有知名 Operator**：etcd-operator、prometheus-operator、cert-manager

## 工作原理
```
用户创建 CR → Controller 监听到变化
           → Reconcile 对比当前 vs 期望状态
           → 创建/修改/删除相关 K8s 资源
           → 更新 CR Status 反馈结果
```

## 开发工具
| 工具 | 说明 |
|------|------|
| **kubebuilder** | 官方推荐的 Operator 开发框架（Go） |
| **Operator SDK** | Red Hat 出品，封装了 kubebuilder |
| **Kopf** | Python 版 Operator 框架 |
| **Java Operator SDK** | Java 版 |

## 常见场景
- 部署和管理有状态应用（数据库、消息队列）
- 自动备份与恢复数据库
- 基于 CR 实现的自定义 CI/CD 流程
- 编排多云/混合云资源
