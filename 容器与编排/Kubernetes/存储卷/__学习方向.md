# K8s 存储卷 — 学习方向

## 核心概念
- **emptyDir**：Pod 内临时共享存储，Pod 删除即消失
- **hostPath**：挂载宿主机目录（不推荐生产）
- **PV / PVC**：持久化存储的解耦设计
  - PV（PersistentVolume）：集群级别的存储资源
  - PVC（PersistentVolumeClaim）：用户对存储的请求
  - StorageClass：动态制备 PV
- **ConfigMap / Secret**：配置和敏感信息挂载

## 存储方案选型
| 方案 | 类型 | 适用场景 |
|------|------|----------|
| **NFS** | ReadWriteMany | 多 Pod 共享读写 |
| **Ceph RBD** | ReadWriteOnce | 高性能块存储 |
| **CephFS** | ReadWriteMany | 共享文件系统 |
| **CSI 驱动** | 各种 | 对接云厂商存储（阿里云 Disk/NAS/OSS） |
| **Local PV** | ReadWriteOnce | 本地 SSD 高 IO 场景 |

## 常见场景
- 数据库（MySQL/PostgreSQL）需要持久化数据
- 多个 Pod 共享同一个配置文件（ConfigMap 热更新）
- Pod 重启后数据丢失 -> 需要 PVC 持久化
