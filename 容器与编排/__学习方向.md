# 容器与编排 — 学习方向（含云原生与云平台）

## 核心领域

| 方向 | 内容 |
|------|------|
| **容器化** | Docker、镜像构建、Dockerfile 最佳实践 |
| **容器编排** | Kubernetes（K8s）核心概念与实操 |
| **服务网格** | Istio、Envoy |
| **CI/CD** | GitLab CI、GitHub Actions、ArgoCD |
| **可观测性** | Prometheus + Grafana + Loki + Jaeger |
| **云平台** | 阿里云/AWS/腾讯云的核心产品 |
| **Serverless** | ASK（阿里云）、AWS Lambda |

## 推荐学习路径

```
入门期：
  Docker → 基本 K8s 操作（pod/deploy/service）→ 集群搭建

进阶期：
  K8s 进阶（ingress/storage/configmap/helm）→ Prometheus

深入期：
  CI/CD 流水线 → Istio 服务网格 → Operator 开发
```

## 常用认证参考
- **CKA**（Certified Kubernetes Administrator）：K8s 管理员认证
- **CKAD**（Certified Kubernetes Application Developer）：K8s 应用开发者
