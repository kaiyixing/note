# Jaeger 链路追踪 — 学习方向

## 核心概念
- **Trace**：一次完整请求的调用链路
- **Span**：链路中的单个操作（HTTP 调用、数据库查询等）
- **Context Propagation**：上下文传播（Trace ID 在服务间传递）
- **Sampling**：采样策略（生产环境不能全量采集）
- **Jaeger 架构**：Agent → Collector → Storage (ES/Cassandra) → UI

## 部署方式
```bash
docker run -d --name jaeger \
  -e COLLECTOR_ZIPKIN_HOST_PORT=:9411 \
  -p 6831:6831/udp \
  -p 16686:16686 \
  jaegertracing/all-in-one:latest
```
访问 `http://localhost:16686` 看 UI。

- 新版本上线后性能对比（A/B 链路耗时对比）
