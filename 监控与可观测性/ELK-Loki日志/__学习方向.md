# ELK / Loki 日志 — 学习方向

## 核心概念
### ELK Stack
| 组件 | 作用 |
|------|------|
| **Elasticsearch** | 日志存储 + 搜索引擎 |
| **Logstash** | 日志采集 + 过滤 + 转换 |
| **Kibana** | 可视化查看 + 搜索 |
| **Filebeat** | 轻量级日志采集（替代 Logstash Agent 角色） |

### Loki（Grafana 出品）
- **轻量级日志系统**，只索引标签（不索引全文内容）
- 与 Prometheus 共用标签体系（`job`、`instance`...）
- 配合 Grafana 使用，无需 Kibana

## 对比

| 方面 | ELK | Loki |
|------|-----|------|
| 资源消耗 | 高（ES 很吃内存） | 低 |
| 全文搜索 | 强 | 较弱 |
| 与 Prometheus 集成 | 一般 | 原生集成 |
| 适用场景 | 复杂日志分析 | 快速日志查看 + 关联指标 |

## 常见场景
- 从海量日志中搜索某个错误码
- 看某个时间段所有 5xx 请求日志
- 结合 CPU 飙高和日志定位根因
