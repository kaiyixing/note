# 告警管理 — 学习方向

## 核心概念
- **告警三要素**：指标采集 → 告警规则 → 通知送达
- **Alertmanager**（Prometheus 生态）：分组、抑制、静默、路由
- **告警分级**：P0（致命）> P1（严重）> P2（警告）> P3（通知）
- **告警收敛**：避免告警风暴（重复告警合并）
- **On-Call 机制**：值班轮换、升级策略

## 告警规则示例
```yaml
# Prometheus 告警规则
groups:
  - name: node
    rules:
      - alert: NodeDown
        expr: up == 0
        for: 1m
        labels: { severity: critical }
        annotations:
          summary: "节点 {{ $labels.instance }} 宕机"
```

## 常见场景
- 某台机器挂了，只发一条告警而不是 100 条
- 晚上收到告警，如何快速判断是 P0 还是 P3
- 运维值班，告警通知到正确的人
