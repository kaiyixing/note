## 数据抓取流程

### 第一步：节点指标采集 (node-exporter)

```
┌─────────────────────────────────────────────────────────────────────┐
│                        node-exporter (DaemonSet)                     │
│  运行在每个节点上，收集服务器基础指标                                  │
└─────────────────────────────────────────────────────────────────────┘

收集的指标类型：
┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   CPU       │  │   内存      │  │   磁盘      │  │   网络      │
│   使用率    │  │   使用率    │  │   IO        │  │   流量      │
└─────────────┘  └─────────────┘  └─────────────┘  └─────────────┘

暴露端点: http://<节点IP>:9100/metrics
```

### 第二步：Prometheus 抓取数据

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Prometheus Server                               │
│                                                                     │
│  配置抓取规则:                                                       │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │  job_name: 'kubernetes-nodes'                                │  │
│  │    static_configs:                                            │  │
│  │      - targets: ['192.168.233.10:9100',                      │  │
│  │                  '192.168.233.11:9100',                      │  │
│  │                  '192.168.233.12:9100']                       │  │
│  └───────────────────────────────────────────────────────────────┘  │
│                                                                     │
│  抓取频率: 默认 15s 一次                                             │
└─────────────────────────────────────────────────────────────────────┘
```

### 第三步：数据存储与查询

```
┌─────────────────────────────────────────────────────────────────────┐
│                         TSDB 存储                                    │
│                                                                     │
│  存储格式:                                                           │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │ metric_name{label1="value1",label2="value2"} timestamp value │  │
│  │                                                               │  │
│  │ example:                                                     │  │
│  │ node_cpu_seconds_total{mode="idle",cpu="0"} 1234567890 95.5 │  │
│  └───────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### 第四步：可视化展示 (Grafana)

```
┌─────────────────────────────────────────────────────────────────────┐
│                         Grafana                                      │
│                                                                     │
│  1. 从 Prometheus 读取数据                                           │
│     URL: http://prometheus-kube-prometheus-prometheus:9090         │
│                                                                     │
│  2. 展示预置 Dashboard                                              │
│     - Kubernetes cluster monitoring (ID: 6417)                     │
│     - Node exporter full (ID: 1860)                                │
│     - etc.                                                         │
└─────────────────────────────────────────────────────────────────────┘
```

## 关键组件说明

| 组件 | 作用 | 端口 |
|------|------|------|
| **node-exporter** | 采集节点硬件/系统指标 | 9100 |
| **kube-state-metrics** | 采集 K8s 对象状态（Deployment/Service/Pod等） | 8080 |
| **Prometheus** | 定时抓取并存储指标数据 | 9090 |
| **Grafana** | 可视化展示 | 3000 |
| **Alertmanager** | 处理告警通知 | 9093 |
