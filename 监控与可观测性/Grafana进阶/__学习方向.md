# Grafana 进阶 — 学习方向

## 基础回顾
- DataSource 配置（Prometheus、Loki、ES、MySQL...）
- Dashboard 创建与 Panel 编辑
- 变量（Variables）：模板化 dashboard

## 进阶主题

### 1. 告警
- Grafana 内置 Alerting（取代老的 Grafana Alert）
- 告警规则、联系人、通知策略
- 与 Alertmanager 联动

### 2. 高级 Panel
- **Time Series** 面板：多维度对比
- **Stat** 面板：关键数字展示
- **Table** 面板：表格展示（可排序）
- **Bar Chart / Histogram**：分布展示
- **Geomap**：地理分布

### 3. Dashboard 最佳实践
- 按层级组织：服务层 → 系统层 → 业务层
- 关键指标在左上角（人眼自然浏览顺序）
- 合适的刷新间隔与时间范围
- Dashboard 命名和标签规范

### 4. Explore 模式
- 临时查询（Ad-hoc 分析）
- 多数据源联合查询
- 从指标到日志的下钻
