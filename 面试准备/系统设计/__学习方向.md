# 系统设计 — 学习方向

## 核心考点
- **高并发**：QPS、TPS、并发用户数预估
- **高可用**：冗余、故障转移、降级、限流
- **高性能**：缓存、CDN、异步、读写分离
- **一致性**：强一致性 vs 最终一致性，CAP 理论
- **可扩展**：水平扩容、无状态设计、分库分表

## 经典题目

| 题目 | 核心考点 |
|------|----------|
| 短链接系统 | 哈希映射、Base62、读写比例 |
| 秒杀系统 | 限流、削峰、防超卖、隔离 |
| 微信朋友圈 | Feed 流推拉模式、时间线 |
| 聊天系统 | WebSocket、消息顺序、离线消息 |
| 分布式 ID | Snowflake、Leaf、美团 ID |
| 配置中心 | 推/拉模式、Watch 机制 |
| 搜索引擎 | 倒排索引、分词、排序 |
| 推荐系统 | 协同过滤、Embedding、召回+排序 |

## 设计步骤
1. **明确需求**：功能 + 非功能（QPS、延迟、数据量）
2. **数据估算**：存储量、带宽、并发数
3. **核心设计**：数据模型、API 设计
4. **架构设计**：分层架构、关键组件选型
5. **深入细节**：一致性、容错、扩展性
