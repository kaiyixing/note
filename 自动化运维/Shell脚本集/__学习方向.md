# Shell 脚本 — 学习方向

## 基础必会

### 变量与参数
```bash
name="world"
echo "Hello, $name"
echo "脚本名: $0"
echo "参数1: $1"
echo "参数个数: $#"
```

### 条件判断
```bash
if [ -f "/etc/passwd" ]; then echo "文件存在"; fi
# 文件判断: -f 文件, -d 目录, -e 存在, -z 空字符串
# 数值比较: -eq, -ne, -gt, -lt
```

### 循环
```bash
for f in *.log; do echo "处理 $f"; done
while read line; do echo "$line"; done < file.txt
```

### 常用命令组合
```bash
# 查找并替换
grep -rl "old" . | xargs sed -i 's/old/new/g'

# 统计日志
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -10

# 批量操作
for ip in $(cat ip_list.txt); do ssh "$ip" "uptime"; done
```

## 常用陷阱
- 变量记得加双引号：`"$var"`（否则空格会拆成多参数）
- `set -e` 遇错即停（避免错误继续执行）
- `$(command)` 替换反引号 `\`command\``
