# Terraform 与 IaC — 学习方向

## 核心概念
- **IaC**（Infrastructure as Code）：基础设施即代码
- **声明式**：描述目标状态，工具自动实现
- **State**：Terraform 的状态文件（记录当前资源）
- **Provider**：云厂商/服务的 API 适配层
- **Resource**：具体资源（ECS、RDS、VPC...）
- **Module**：可复用的资源模板

## 基本工作流
```bash
terraform init       # 初始化（下载 provider）
terraform plan       # 预览变更
terraform apply      # 执行变更
terraform destroy    # 销毁资源
```

## 实操清单
- [ ] 用 Terraform 在云上创建一台虚拟机
- [ ] 创建 VPC + 子网 + 安全组 + 虚拟机（完整网络拓扑）
- [ ] 使用变量（`variables.tf`）和环境隔离（`tfvars`）
- [ ] 从 State 中移除/导入资源
- [ ] 写一个 Module 复用（比如标准的 web 模块）
- [ ] 配合 CI/CD 自动化部署基础设施
- [ ] Terraform + Ansible 组合使用（Terraform 建机器，Ansible 配软件）

## 学习路径
1. 理解 IaC 思想和 Terraform 基本用法
2. 掌握 Terraform HCL 语法（resource、data、variable、output）
3. 学习 State 管理和远程状态存储（S3/Terraform Cloud）
4. 写 Module 复用基础设施代码

## 常见场景
- 一键创建开发/测试/生产环境
- 基础设施版本控制（Git 管理 .tf 文件）
- 多云管理（AWS + 阿里云 + 私有云）
