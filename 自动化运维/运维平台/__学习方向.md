# 运维平台 — 学习方向

## 核心功能
| 模块 | 说明 |
|------|------|
| **CMDB** | 资产配置管理（服务器、IP、应用关系） |
| **发布系统** | 代码/配置的自动化发布上线 |
| **监控告警** | 指标采集、告警规则、通知 |
| **工单系统** | 审批流程、变更管理 |
| **作业平台** | 批量脚本执行、定时任务 |
| **权限管理** | 用户、角色、操作审计 |

## 常见方案
- **自建开源**：Spug、Jumpserver（堡垒机 + 运维平台）
- **云平台**：阿里云 OOS、AWS Systems Manager
- **商业方案**：睿象云、蓝鲸智云
- **K8s 平台**：Rainbond、KubeSphere

## 实操清单
- [ ] 明确需求：给多大团队用？管多少机器？
- [ ] 调研现有开源方案（Spug 轻量，蓝鲸重量）
- [ ] 搭建 Spug 体验 CMDB + 发布 + 监控
- [ ] 基于 Django/Vue 自建一个简单的发布平台原型
- [ ] 接入 LDAP/OAuth 统一认证

## 设计原则
- **最小可行**：先解决发布和 CMDB 两个核心痛点
- **标准化**：统一 OS 镜像、目录结构、命名规范
- **自动化优先**：能自动的不要手动
- **安全合规**：操作审计、权限最小化
