# 算法 — 学习方向

## 核心数据结构

| 结构 | 常见题型 |
|------|----------|
| **数组** | 二分查找、双指针、滑动窗口 |
| **链表** | 反转、快慢指针、合并有序链表 |
| **栈/队列** | 括号匹配、单调栈、LRU Cache |
| **哈希表** | Two Sum、计数、去重 |
| **树** | 遍历（前/中/后/层序）、BST、最近公共祖先 |
| **堆** | Top K、合并 K 个有序链表 |
| **图** | DFS、BFS、拓扑排序、最短路径 |

## 核心算法

| 算法 | 掌握程度 |
|------|----------|
| **排序** | 快排（手写）、归并排序思想 |
| **二分查找** | 标准写法 + 变体（找边界） |
| **动态规划** | 背包问题、最长子序列、斐波那契类 |
| **回溯** | 排列、组合、子集、N 皇后 |
| **BFS/DFS** | 树的层序遍历、图的遍历、岛屿问题 |

## 刷题建议
- **起步**：LeetCode Hot 100 + 剑指 Offer（精做 50 题）
- **重点**：数组、字符串、链表、二叉树、哈希表优先
- **节奏**：每天 1-2 题，重在理解思路，不是背题
- **语言**：用你最熟悉的语言（面试推荐 Python/Java/Go）
