# Transformer 架构原理详解（面试复习讲义）

> 本文综合经典论文《Attention Is All You Need》（Vaswani 等，2017）与科普视频《一小时从 Transformer 到大模型！》（飞天闪客，"理解AI"合集第 10 集）整理而成，适用于算法 / 大模型岗位面试复习。
> 文中标注「（视频）」的内容来自该科普视频的具体讲解视角。

---

## 0. 一分钟总览

Transformer 是 2017 年提出的**纯注意力序列模型**：用"自注意力 + 前馈网络 + 残差/归一化"替代 RNN/CNN，让每个 token 直接对序列中所有 token 建模相关性，从而支持**并行训练**和**长距离依赖**。现代大模型（GPT、BERT、DeepSeek、Qwen、GLM 等）的底层架构都是它的变体。

一句话串起全流程：**输入进词嵌入+位置编码，经过 N 个"注意力+FFN"的 Block，注意力负责按相关性把上下文信息加权融合，训练目标就是不断预测下一个词。**

---

## 1. 背景：它为什么出现

- 2017 年谷歌《Attention Is All You Need》首次**完全基于注意力机制**构建序列模型，抛弃 RNN/CNN。
- 此前主流序列模型 RNN/LSTM 的两个硬伤：
  - **串行计算**：必须按时间步逐个处理，训练慢、难以并行；
  - **长距离依赖**：信息要经过 O(n) 步才能传递，存在梯度消失和遗忘问题。
- Transformer 的解法：**所有位置并行计算**，任意两个 token 之间只隔一步注意力。

**宏观结构**：编码器-解码器（Encoder-Decoder）。原文配置：编码器 6 层 + 解码器 6 层，d_model=512，多头注意力 8 头，FFN 隐层 2048。

架构示意：

```
输入序列 ──► 词嵌入 ──► 位置编码 ──► ┌─────────────────────────────┐
                                   │  编码器 Encoder（× N 层）     │
                                   │    多头自注意力                │
                                   │    → Add & Norm（残差+归一化）│
                                   │    前馈网络 FFN                │
                                   │    → Add & Norm                │
                                   └──────────────┬──────────────┘
                                                  │ K、V（编码器输出）
                                                  ▼
输出序列（右移一位）─► 词嵌入 ──► 位置编码 ──► ┌─────────────────────────────┐
                                             │  解码器 Decoder（× N 层）     │
                                             │    带掩码多头自注意力          │
                                             │    → Add & Norm               │
                                             │    交叉注意力                  │
                                             │    （Q 来自解码器，            │
                                             │     K、V 来自编码器）          │
                                             │    → Add & Norm               │
                                             │    前馈网络 FFN                │
                                             │    → Add & Norm                │
                                             └──────────────┬──────────────┘
                                                            ▼
                                                 Linear → Softmax
                                                            ▼
                                                  输出词概率分布
```

## 2. 输入表示：词嵌入 + 位置编码

### 2.1 词嵌入（Token Embedding）

把每个 token 通过查表映射为一个稠密向量，之后所有计算都在向量空间里进行。实际规模举例（GPT-2 配置，视频）：**词表大小 50257，词向量维度 768**。

### 2.2 位置编码（Positional Encoding）

自注意力本身**没有顺序概念**（打乱 token 顺序结果不变），必须显式注入位置信息。原文用正弦/余弦函数：

```
PE(pos, 2i)   = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))
```

- 不同频率对应不同位置的"指纹"，模型可以感知相对位置；
- 无需训练、可外推到比训练时更长的序列。
- 现代替代方案：可学习位置编码（BERT）、旋转位置编码 RoPE（LLaMA 等主流）、ALiBi 等。

---

## 3. 自注意力机制（核心）

### 3.1 Q / K / V 的直觉

对每个输入向量 x，通过三个可学习矩阵投影出：

- **Q（Query 查询）**：主动去"问"的请求；
- **K（Key 键）**：挂牌等待被查询的标识；
- **V（Value 值）**：被选中后提供的内容。

**视频原例（今天 / 天气 / 真）**：当前词"真"的新向量 ≈ **0.7×真 + 0.2×天气 + 0.1×今天**，权重就是"上下文词和当前词的相关性"。换句话说，注意力 = **按相关性加权组合上下文**。

### 3.2 缩放点积注意力公式

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V
```

四步：
1. **打分**：Q 与所有 K 做点积，衡量当前位置与每个位置的相关性；
2. **缩放**：除以 √d_k；
3. **归一化**：softmax 得到权重；
4. **加权求和**：权重乘 V 求和，得到该位置的输出。

### 3.3 为什么除以 √d_k

假设 q、k 各分量独立同分布、均值 0 方差 1，则点积的均值仍为 0、**方差为 d_k**。d_k 越大，点积数值越大，softmax 越容易进入梯度饱和区（梯度趋近 0）。除以 √d_k 把方差拉回 O(1)，训练更稳定。

### 3.4 多头注意力（Multi-Head Attention）

```
MultiHead(Q, K, V) = Concat(head₁, …, head_h) · W^O
head_i = Attention(Q·W_i^Q, K·W_i^K, V·W_i^V)
```

把 Q/K/V 切成 h 个头（原文 8 头）**分别独立做注意力再拼接**，让模型在不同子空间同时关注不同类型的依赖（语法、指代、语义等）。

### 3.5 复杂度

- 自注意力：**O(n²·d)**（n 为序列长度，d 为维度）——任意两个位置一步可达；
- 代价：序列变长时平方级开销，催生了 FlashAttention、稀疏注意力、线性注意力等优化。

---

## 4. 前馈网络与残差 / 归一化

### 4.1 前馈网络（FFN）

```
FFN(x) = max(0, x·W₁ + b₁)·W₂ + b₂
```

对每个位置独立做两次线性变换 + 非线性激活（原文 ReLU，现代常用 GELU），提供非线性特征加工。配合注意力的"信息融合"，FFN 负责"特征变换"。

### 4.2 残差连接（Residual Connection）

每个子层输出：

```
LayerNorm(x + Sublayer(x))
```

作用：缓解深层梯度消失，让几十上百层可以稳定训练（现代大模型动辄 32/64/128 层）。

### 4.3 LayerNorm vs BatchNorm

| 维度 | LayerNorm | BatchNorm |
|---|---|---|
| 归一化对象 | 每个样本的**特征维** | 每个特征在 **batch 维** |
| 是否依赖 batch | 否 | 是 |
| 变长序列 | 适配 | 不适配 |
| Transformer 用哪个 | ✅ 用 LayerNorm | ❌ |

## 5. 编码器（Encoder）

- **输入**：词嵌入 + 位置编码。
- **每层结构**：多头自注意力 → Add & Norm → 前馈网络 → Add & Norm；**堆叠 N 层**（原文 6 层）。
- **自注意力是双向的**：每个位置能看到完整输入序列。
- **输出**：每个位置一个融合了全局上下文信息的向量。

---

## 6. 解码器（Decoder）

- **输入**：右移一位的输出序列（训练时 Teacher Forcing）。
- **每层结构**（比编码器多一层交叉注意力）：

```
带掩码的多头自注意力 → Add & Norm
→ 交叉注意力（Q 来自解码器，K、V 来自编码器）→ Add & Norm
→ 前馈网络 → Add & Norm
```

- **掩码自注意力**：位置 i 只能看到 0~i 的 token（softmax 前把未来位置设为 -∞），保证自回归生成时不"偷看未来"。
- **交叉注意力**：Q 来自解码器自身，K、V 来自编码器输出——解码器据此"查询"输入序列的信息，实现编码-解码融合。
- **输出**：Linear → Softmax → 词表上的概率分布。

### 6.1 训练 vs 推理的差异

| | 训练 | 推理 |
|---|---|---|
| 输入 | 整句并行（真实目标词右移一位） | 已生成的词逐词喂入 |
| 方式 | Teacher Forcing + 掩码防偷看 | 自回归逐词生成 |
| 效率 | 一次前向算完所有位置 | 每步只预测下一个词 |

---

## 7. 为什么 Transformer 能取代 RNN/CNN

| 维度 | RNN | CNN | Transformer |
|---|---|---|---|
| 顺序操作数 | O(n) | O(1)（层级并行） | **O(1)** |
| 最大路径长度 | O(n) | O(log_k n) | **O(1)** |
| 每层复杂度 | O(n·d²) | O(k·n·d²) | O(n²·d) |

- **并行**：所有位置同时计算，训练快几个量级，能吃更大数据；
- **长距离依赖**：任意两个 token 一步直达，解决 RNN 的梯度消失和长程遗忘；
- **可扩展**：结构高度规整，便于堆层数、加宽度，催生 BERT/GPT 范式。

**代价**：注意力 O(n²·d)，长序列开销大——这是 FlashAttention、稀疏注意力、MQA/GQA、MLA 等优化的动机。

---

## 8. 训练：不断预测下一个词

- GPT 系预训练目标：**next-token prediction（预测下一个词）**。给前文，预测下一个 token 的概率分布，用交叉熵最大化真实词的 log 概率。
- 视频示例：给定"的读者们最帅了嘿才怪"，模型预测下一个词——"的"概率 0.94，其余词 0.03 / 0.01 / 0.01……（视频）
- 为什么解码器要掩码：预测第 i+1 个词时只能看前 i 个词，训练时也必须保持一致。
- 海量文本 + 大规模参数 → 涌现出语言理解与推理能力。

## 9. 从 Transformer 到大模型

### 9.1 两大路线

| 模型 | 结构 | 特点 | 代表 |
|---|---|---|---|
| BERT | 只用编码器 | 双向，适合理解类任务 | BERT、RoBERTa |
| GPT | 只用解码器 | 自回归，适合生成 | GPT 系列、当代主流大模型 |

### 9.2 架构演进方向（视频视角）

现代开源大模型都是 Transformer 变体，常见改进：

- **位置编码**：RoPE、ALiBi；
- **注意力效率**：FlashAttention、稀疏注意力、MQA/GQA（共享 KV）、MLA（DeepSeek）；
- **稀疏激活**：MoE 混合专家（按 token 路由到部分专家）；
- **长上下文**：KV Cache、滑动窗口、推理缓存优化；
- **对齐训练**：预训练 → SFT → RLHF / DPO。

视频列举了 67 个核心开源模型：DeepSeek V4-Pro（1.6T）、DeepSeek V4-Flash（284B）、Qwen3、GLM-5、Kim K2、MiniMax-M2、Gemma 4、Mistral Small 4 等——无论参数规模如何变化，底层都是 Transformer。（视频）

### 9.3 从 LLM 到 Agent

预测下一个词 → 对话能力 → 工具调用 → **Agent**（模型 + 规划 + 工具 + 记忆，自主完成多步任务）。视频第 7 章专门讲"怎么样才能继续"——把单步预测扩展成多步行动闭环。（视频）

## 10. 面试高频追问（Q&A）

1. **Q：为什么除以 √d_k？**
   A：d_k 越大，Q·K 点积方差越大，softmax 越易饱和、梯度消失；除以 √d_k 把方差拉回 O(1)。

2. **Q：Q / K / V 分别是什么？**
   A：由输入向量经三个可学习矩阵投影得到。Q 负责"查询"，K 负责"被查询"，两者点积得到相关性；softmax 归一化为权重，再对 V 加权求和。

3. **Q：为什么需要位置编码？**
   A：自注意力对位置置换不变（打乱顺序结果相同），模型本身没有顺序信息，必须显式注入。

4. **Q：LayerNorm 和 BatchNorm 的区别？**
   A：LN 按单个样本的特征维归一化，不依赖 batch、适合变长序列；BN 按特征在 batch 维归一化，依赖 batch 统计，序列/小 batch 场景不稳定。

5. **Q：解码器的掩码有什么作用？**
   A：保证自回归——位置 i 只能看 0~i，防止"偷看未来"造成信息泄漏。

6. **Q：训练和推理时解码器有什么不同？**
   A：训练并行输入整句（Teacher Forcing + 右移一位 + 掩码）；推理逐词自回归，用已生成词预测下一个。

7. **Q：Transformer 的复杂度？**
   A：注意力 O(n²·d)，任意两位置一步直达；这是并行和长距离建模的代价。

8. **Q：残差连接的作用？**
   A：缓解深层梯度消失/退化，让几十上百层可训练。

9. **Q：为什么 Transformer 比 RNN 更适合并行和长序列？**
   A：顺序操作数 O(1) vs O(n)，最大路径长度 O(1) vs O(n)。

10. **Q：多头注意力为什么需要多头？**
    A：不同头在不同子空间关注不同类型的依赖关系（语法、指代、语义），拼接后表达能力更强。

11. **Q：BERT 和 GPT 的区别？**
    A：BERT 只用编码器、双向、适合理解；GPT 只用解码器、自回归、适合生成，是当代大模型主流。

12. **Q（加分）什么是 KV Cache / GQA / MoE？**
    A：KV Cache 缓存历史 K/V 避免重复计算；GQA 分组共享 KV 减少显存；MoE 用路由器把 token 分给部分专家，扩大参数量而不等比增加计算量。
