# Transformer 架构

> 关联：[[面试与成长/面试准备/算法/__学习方向|算法学习方向]] · [[LLM]] · [[大模型推理优化]]

## 〇、一句话核心

Transformer 彻底抛弃 RNN 的"顺序处理"，用 **Self-Attention** 让序列里每个位置能"看到"其他所有位置，**并行化**训练，是 GPT / BERT / 大模型的基础。

- 论文：*Attention Is All You Need*（2017，Google）
- 类比：开会时每人戴耳机**同时**听所有人发言，并自己判断"谁的话跟我关系大"（attention 权重）→ 能并行、能捕捉长距离关系。RNN 则是"传话筒"，话只能从左往右传，容易忘开头。

## 一、核心组件（面试必须能画出来）

```
输入 (tokens)
  │
  ├─→ Embedding + 位置编码(PE)
  │
  ▼
┌─────────────────────────────┐  重复 N 层 (GPT 6~96 层)
│  Multi-Head Self-Attention │
│  + 残差连接 + LayerNorm    │
│  Feed Forward (两层全连接) │
│  + 残差连接 + LayerNorm    │
└─────────────────────────────┘
  │
  ▼
输出 (下一个词概率 / 语义向量)
```

### 1. Self-Attention（最核心，必问）
每个 token 算三个向量：
- **Q（Query）**：我需要什么信息
- **K（Key）**：我能提供什么标签
- **V（Value）**：我的实际内容

公式：
```
Attention(Q,K,V) = softmax( Q·Kᵀ / √d_k ) · V
```
- `Q·Kᵀ`：算每个词对别的词的"相关度"
- `√d_k`：**缩放因子**，防止点积值过大让 softmax 梯度消失
- `softmax`：归一化成权重
- 加权求和 V → 每个词得到"融合了全句信息"的新表示

### 2. Multi-Head（多头）
把 `d_k` 拆成 **h 个头**，每个头在不同子空间学不同类型的关系（有的关注语法、有的关注指代、有的关注远距离依赖），最后拼接。类比：让多组人分别讨论不同话题再汇总。

### 3. 位置编码（PE）
Attention 本身**不感知顺序**（打乱输入结果不变），所以加位置编码告知"第几个词"。早期用正弦函数，现在多为可学习向量。

### 4. 残差连接 + LayerNorm
- 残差：`x + Sublayer(x)`，深层网络可训练、信息不丢
- LayerNorm：归一化每个位置的向量，稳定训练

## 二、Encoder / Decoder / Encoder-Decoder（两大派系，高频）

| 类型 | 代表 | 结构特点 | 典型任务 |
|------|------|----------|----------|
| **Encoder** | BERT | 双向，看全句 | 分类、抽取、检索、理解 |
| **Decoder** | GPT / ChatGPT | **因果掩码**：只能看左边 | 自回归生成、对话、补全 |
| **Encoder-Decoder** | T5、机器翻译 | 前编码源、后解码目标 | 翻译、摘要 |

关键区别：Decoder 用**因果掩码（causal mask）**，让模型生成时不能"偷看"答案右边的词。

## 三、必会追问（八股）

1. **为什么 RNN 被取代？** 顺序计算不能并行 + 长距离依赖梯度消失；Transformer 全局并行 + 任意两词直接连接。
2. **计算复杂度？** 自注意力 O(n²)，序列越长越贵 → 推理贵、长上下文贵。引出 FlashAttention、稀疏注意力、KV Cache。
3. **KV Cache 是什么？** 生成时把已算过的 K/V 缓存，避免每步重算，**显存换时间**，加速推理。
4. **参数量大头？** Embedding + 每层 FFN（通常 4×d_model 维度）+ Attention 投影矩阵。
5. **d_model 常见值？** GPT-2 768~1600，LLaMA 系 4096+，越大越强但越贵。

## 3.5 词嵌入矩阵（Token Embedding Matrix）

- 形状：`[vocab_size, d_model]`，本质是一张**可学习的查表词典**
- 输入 token ID → 取出矩阵中对应一行 → 得到该词的 d_model 维稠密向量
- 初始化：随机正态分布，训练中随梯度更新；高频词更新更稳定，低频词易欠拟合
- 常见优化：**weight tying**（输入 embedding 与输出层共享同一矩阵），减少参数量
- 参数量占比：`V × D`，如 LLaMA-7B 词表 32000 × D=4096 ≈ 1.3 亿，常占总参数 20%~50%
- 类比：查字典——输入词 ID，翻到那一行，拿到一组数字
