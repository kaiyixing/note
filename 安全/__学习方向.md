# 安全 — 学习方向

## 核心领域

| 方向 | 说明 |
|------|------|
| **系统安全** | Linux 安全加固、SELinux、AppArmor |
| **网络安全** | iptables/nftables、firewalld、WAF |
| **应用安全** | HTTPS、OWASP Top 10、JWT |
| **容器安全** | 镜像扫描、K8s RBAC、Pod 安全策略 |
| **认证与授权** | LDAP、OAuth2、OIDC、SSO |
| **加密与证书** | TLS/SSL、Let's Encrypt、mTLS |
| **审计与合规** | 日志审计、等保、GDPR |
| **密钥管理** | HashiCorp Vault、KMS |

## 实操清单
- [ ] Linux 基线安全加固（SSH、密码策略、防火墙）
- [ ] iptables 配置端口转发和访问控制
- [ ] 申请 Let's Encrypt 免费证书并配置自动续期
- [ ] K8s RBAC 配置（ServiceAccount + Role + RoleBinding）
- [ ] 部署 HashiCorp Vault 管理密钥
- [ ] 配置 Nginx WAF（ModSecurity）
- [ ] Docker 镜像漏洞扫描（Trivy）

## 日常要点
- **最小权限原则**：给刚刚好的权限，不要多
- **纵深防御**：网络层 + 系统层 + 应用层都要做
- **日志审计**：谁在什么时候做了什么操作
