## jq — JSON 处理器

**安装**: `apt install jq` 或 `brew install jq`

**核心用法**: `jq '<过滤器>' <文件>`，也可以 pipe 输入。

常用操作：

```bash
# 读取字段
cat data.json | jq '.name'

# 数组遍历
jq '.[].name' data.json

# 条件过滤
jq '.[] | select(.age > 18)' data.json

# 格式化/彩色输出
jq . data.json
```

基本语法就是 `.key` 取字段，`.[]` 遍历数组，`|` 管道，`select()` 过滤，`{...}` 重组对象。

## yq — YAML 处理器

**安装**: `pip install yq`（依赖 jq）或 `brew install yq`

它本质上是 **jq 的 YAML 包装**，语法与 jq 完全一致，只是输入输出是 YAML：

```bash
# 读 YAML 字段
yq '.spec.replicas' deploy.yaml

# 修改并写回
yq '.spec.replicas = 3' -i deploy.yaml

# YAML ↔ JSON 互转
yq -o=json . deploy.yaml     # YAML -> JSON
yq -p=json . data.json       # JSON -> YAML
```

---

**对比总结**：

| 特性 | jq | yq |
|------|-----|----|
| 输入格式 | JSON | YAML (也支持 JSON) |
| 输出格式 | JSON | YAML (可 `-o=json`) |
| 过滤语法 | 自己的 DSL | **同 jq 语法** |
| 适用场景 | API 响应、日志、配置 | K8s manifest、CI 配置、Ansible |

> 注意：go 版 `yq`（`mikefarah/yq`）存在，语法略有不同但功能类似。Linux 包管理器装的一般是 Python 版，依赖 jq。
