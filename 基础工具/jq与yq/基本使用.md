## 第一章：jq — JSON 命令行处理器

jq 是 JSON 处理的事实标准工具。它的设计哲学是用**声明式过滤器**来描述你想从 JSON 中提取什么，而不是教计算机怎么一步步提取。

### 1.1 安装

#### Linux

```bash
# Debian / Ubuntu
sudo apt install jq

# RHEL / CentOS / Fedora
sudo yum install jq          # CentOS 7
sudo dnf install jq          # Fedora / RHEL 8+

# Alpine
apk add jq

# Arch
sudo pacman -S jq

# openSUSE
sudo zypper install jq
```

#### macOS

```bash
brew install jq
```

#### Windows

```bash
# 方案一：scoop
scoop install jq

# 方案二：chocolatey
choco install jq

# 方案三：winget
winget install jq

# 方案四：直接下载 exe
# 访问 https://jqlang.github.io/jq/download/ 下载 jq-win64.exe
# 重命名为 jq.exe 并加入 PATH
```

#### 验证安装

```bash
jq --version
# 输出示例：jq-1.7.1
```

### 1.2 基础过滤器

#### Identity 过滤器 `.`

最简单的过滤器，不做任何转换，直接输出输入内容。常用于格式化输出。

```bash
echo '{"name":"alice","age":30}' | jq '.'
# 输出（格式化 + 彩色）：
# {
#   "name": "alice",
#   "age": 30
# }
```

#### 对象索引

```bash
# 读取顶层字段
echo '{"name":"alice","age":30}' | jq '.name'
# "alice"

# 嵌套字段
echo '{"user":{"name":"alice","contact":{"email":"a@b.com"}}}' | jq '.user.contact.email'
# "a@b.com"

# 安全访问（如果key不存在，返回 null 而不是报错）
echo '{"name":"alice"}' | jq '.age?'
# null

# 实际上 .key 是 ."key" 的语法糖，key 包含特殊字符时用引号
echo '{"my-key":"value"}' | jq '."my-key"'
# "value"
```

#### 数组索引

```bash
json='[10,20,30,40,50]'

# 按位置取（0 基）
echo "$json" | jq '.[0]'     # 10
echo "$json" | jq '.[2]'     # 30

# 负数索引从末尾数
echo "$json" | jq '.[-1]'    # 50
echo "$json" | jq '.[-2]'    # 40

# 切片 [start:end]，左闭右开
echo "$json" | jq '.[0:3]'   # [10,20,30]
echo "$json" | jq '.[1:4]'   # [20,30,40]
echo "$json" | jq '.[:3]'    # [10,20,30]（从头到位置3）
echo "$json" | jq '.[2:]'    # [30,40,50]（从位置2到尾）

# 步长（jq 1.7+）
echo "$json" | jq '.[::2]'   # [10,30,50]
echo "$json" | jq '.[1::2]'  # [20,40]
```

#### 数组迭代 `.[]`

把数组的每个元素展开成独立的流。这是 jq 的核心操作之一。

```bash
json='[{"id":1,"name":"a"},{"id":2,"name":"b"}]'

# 遍历数组，取出每个元素的 name
echo "$json" | jq '.[].name'
# "a"
# "b"

# 对比 .[].name 和 .name：
#   .[].name → 遍历每个元素，取 name
#   .name     → 找顶层 name 字段（不存在就 null）
```

#### 组合使用

```bash
# 数组中的对象嵌套
echo '[{"user":{"name":"alice"}},{"user":{"name":"bob"}}]' | jq '.[].user.name'
# "alice"
# "bob"

# 取数组的第一个元素的某个字段
echo '{"results":[{"id":1,"data":"x"},{"id":2,"data":"y"}]}' | jq '.results[0].data'
# "x"
```

### 1.3 核心操作符

#### 管道 `|`

跟 Unix 管道的语义完全一致：左侧的输出成为右侧的输入。

```bash
echo '[1,2,3]' | jq '.[] | . * 2'
# 2
# 4
# 6

# 每个元素经过多个过滤器
echo '[{"a":1,"b":2},{"a":3,"b":4}]' | jq '.[] | .a + .b'
# 3
# 7
```

#### 逗号 `,`

逗号产生多个输出——对同一个输入依次应用左右两侧的过滤器，各自独立输出。

```bash
echo '{"name":"alice","age":30}' | jq '.name, .age'
# "alice"
# 30

# 每个数组元素产生两条输出
echo '[1,2,3]' | jq '.[] | ., .*2'
# 1
# 2
# 2
# 4
# 3
# 6
```

#### 可选操作符 `.?`

`.` 访问对象属性时，如果中间某个 key 不存在会报错。`.` 安全版 `.?` 遇到 null 就停止。

```bash
# 不安全的写法
echo '{"a":{"b":1}}' | jq '.a.c.d'
# 报错：Cannot index string with string "d"

# 安全写法
echo '{"a":{"b":1}}' | jq '.a.c?.d'
# null（不报错）

# 链式安全
echo 'null' | jq '.[].name?'  # 什么都不输出（不报错）
```

#### 另一些重要操作符

```bash
# 赋值操作符（配合 -i 修改文件）
# =  直接赋值
# |=  更新（左侧表达式计算结果作为新值）
# += -= *= /=  算术赋值

# 空合并操作符 //
# 如果左侧为 null 或 false，用右侧代替
echo '{"a":null}' | jq '.a // "default"'
# "default"

# 逻辑操作符
# and, or, not
echo 'true' | jq '. and true'    # true
echo 'true' | jq '. and false'   # false
```

### 1.4 内置函数详解

#### 类型判断与检查

```bash
# type — 返回值的 JSON 类型名
echo '{"a":[1,2],"b":"str","c":42,"d":null,"e":true}' | jq '{a: .a|type, b: .b|type, c: .c|type, d: .d|type, e: .e|type}'
# {"a":"array","b":"string","c":"number","d":"null","e":"boolean"}

# has(key) — 对象是否包含某个 key
echo '{"name":"alice","age":30}' | jq 'has("name")'    # true

# in — 检查输入是否在给定的对象/数组中（与 has 参数相反）
echo '"name"' | jq '. in {"name":"alice","age":30}'     # true

# contains(element) — 字符串包含、数组包含、对象包含
echo '"foobar"' | jq 'contains("foo")'    # true
echo '[1,2,3]' | jq 'contains([1,2])'     # true（子集）
echo '{"a":1,"b":2}' | jq 'contains({a:1})'  # true

# isempty(expr) — 表达式是否产生空流
echo 'null' | jq 'isempty(.[]?)'          # true
```

#### 聚合函数

```bash
# length — 字符串长度、数组长度、对象 key 数量
echo '"hello"' | jq 'length'              # 5
echo '[1,2,3]' | jq 'length'              # 3
echo '{"a":1,"b":2}' | jq 'length'        # 2

# add — 数组求和（或字符串拼接）
echo '[1,2,3]' | jq 'add'                 # 6
echo '["a","b","c"]' | jq 'add'           # "abc"

# min / max — 数组最小/最大值
echo '[3,1,4,1,5]' | jq 'min'            # 1
echo '[3,1,4,1,5]' | jq 'max'            # 5

# min_by / max_by — 按某字段取极值对象（jq 1.6+）
echo '[{"n":3},{"n":1},{"n":4}]' | jq 'min_by(.n)'
# {"n":1}
```

#### 数组操作函数

```bash
# map(f) — 每个元素应用过滤器 f，相当于 .[] | f 但输出数组
echo '[1,2,3]' | jq 'map(. * 2)'          # [2,4,6]
echo '[{"x":1},{"x":2}]' | jq 'map(.x)'   # [1,2]

# select(condition) — 过滤数组元素
echo '[1,2,3,4,5]' | jq 'map(select(. > 2))'    # [3,4,5]
echo '{"items":[{"n":1},{"n":7},{"n":3}]}' | jq '.items | map(select(.n > 2))'
# [{"n":7},{"n":3}]

# select 直接与 .[] 配合
echo '[{"name":"a","age":20},{"name":"b","age":15}]' | jq '.[] | select(.age >= 18) | .name'
# "a"

# sort / sort_by — 排序
echo '[3,1,4,1,5]' | jq 'sort'            # [1,1,3,4,5]
echo '[{"n":3},{"n":1},{"n":2}]' | jq 'sort_by(.n)'
# [{"n":1},{"n":2},{"n":3}]

# reverse — 反转数组
echo '[1,2,3]' | jq 'reverse'             # [3,2,1]

# unique / unique_by — 去重
echo '[1,2,1,3,2,3]' | jq 'unique'       # [1,2,3]
echo '[{"x":1},{"x":2},{"x":1}]' | jq 'unique_by(.x)'
# [{"x":1},{"x":2}]

# group_by — 分组（返回数组的数组）
echo '[{"city":"BJ","name":"a"},{"city":"SH","name":"b"},{"city":"BJ","name":"c"}]' | jq 'group_by(.city)'
# [
#   [{"city":"BJ","name":"a"},{"city":"BJ","name":"c"}],
#   [{"city":"SH","name":"b"}]
# ]

# 分组后统计每组数量
echo '...' | jq 'group_by(.city) | map({city: .[0].city, count: length})'

# flatten — 展平嵌套数组
echo '[[1,2],[3,[4,5]]]' | jq 'flatten'           # [1,2,3,4,5]
echo '[[1,2],[3,[4,5]]]' | jq 'flatten(1)'         # [1,2,3,[4,5]]（只展平一层）

# indices — 查找元素位置
echo '["a","b","c","b"]' | jq 'indices("b")'      # [1,3]
```

#### 字符串操作函数

```bash
# 大小写转换
echo '"Hello World"' | jq 'ascii_upcase'     # "HELLO WORLD"
echo '"Hello World"' | jq 'ascii_downcase'   # "hello world"

# 字符串检查
echo '"hello.txt"' | jq 'startswith("hello")'    # true
echo '"hello.txt"' | jq 'endswith(".txt")'       # true

# 拆分与拼接
echo '"a,b,c"' | jq 'split(",")'                 # ["a","b","c"]
echo '["a","b","c"]' | jq 'join("|")'            # "a|b|c"

# 替换
echo '"hello world"' | jq 'sub("world"; "jq")'   # "hello jq"
echo '"a1b2c3"' | jq 'gsub("[0-9]"; "_")'        # "a_b_c_"

# 字符串 ↔ 数字
echo '"42"' | jq 'tonumber'                      # 42（数字类型）
echo '42' | jq 'tostring'                        # "42"

# 字符串捕获（jq 1.5+）
echo '"2024-01-15"' | jq 'capture("(?<y>[0-9]+)-(?<m>[0-9]+)-(?<d>[0-9]+)")'
# {"y":"2024","m":"01","d":"15"}
```

#### 对象操作函数

```bash
# keys / keys_unsorted — 获取所有 key
echo '{"b":2,"a":1,"c":3}' | jq 'keys'            # ["a","b","c"]（排序）
echo '{"b":2,"a":1,"c":3}' | jq 'keys_unsorted'    # ["b","a","c"]

# del — 删除字段
echo '{"a":1,"b":2,"c":3}' | jq 'del(.b)'         # {"a":1,"c":3}
echo '[{"a":1,"b":2},{"a":3,"b":4}]' | jq 'map(del(.b))'
# [{"a":1},{"a":3}]

# delpaths — 删除多级路径
echo '{"a":{"b":{"c":1}}}' | jq 'delpaths([["a","b","c"]])'
# {"a":{"b":{}}}

# with_entries — 遍历并修改对象的 key-value 对
# 每个 entry 是 { key: ..., value: ... } 对象
echo '{"a":1,"b":2}' | jq 'with_entries(.value *= 2)'
# {"a":2,"b":4}

# 等价写法的拆解：
# to_entries → [{"key":"a","value":1}, {"key":"b","value":2}]
# from_entries ← 逆向操作
echo '{"a":1,"b":2}' | jq 'to_entries'
# [{"key":"a","value":1},{"key":"b","value":2}]

# map_values — 只对值做映射
echo '{"a":1,"b":2}' | jq 'map_values(. * 10)'
# {"a":10,"b":20}
```

#### 高级函数

```bash
# error(msg) — 抛出一个错误，终止过滤
# empty — 不产生任何输出（用于过滤掉元素）
echo '[1,2,3]' | jq '.[] | if . % 2 == 0 then empty else . end'
# 1
# 3

# env — 访问环境变量
jq -n 'env.HOME'
# "/home/user"
```

### 1.5 对象与数组构造

#### 对象构造

```bash
# 最简单的对象构造：{key: expr}
echo '{"a":1,"b":2}' | jq '{sum: (.a + .b), product: (.a * .b)}'
# {"sum":3,"product":2}

# 字段名与值名相同时可以简写
echo '{"name":"alice","age":30}' | jq '{name, age}'
# {"name":"alice","age":30}
# 等价于 {name: .name, age: .age}

# 字段名用变量/表达式
echo '{"name":"alice"}' | jq '{"user.name": .name}'
# {"user.name":"alice"}

# 从两个对象合并
echo '{"a":1}' | jq '{b: 2} + .'
# {"b":2,"a":1}
```

#### 数组构造

```bash
# [expr] — 把 expr 的输出收集成数组
echo '[{"x":1},{"x":2}]' | jq '[.[] | .x]'
# [1,2]

# map 是 [.[] | ...] 的语法糖
echo '[{"x":1},{"x":2}]' | jq 'map(.x)'
# [1,2]

# 重构数据
echo '{"users":["a","b","c"]}' | jq '{names: [.users[] | {name: .}]}'
# {"names":[{"name":"a"},{"name":"b"},{"name":"c"}]}
```

### 1.6 字符串插值

使用 `\(...)` 语法在字符串中嵌入表达式。

```bash
echo '{"name":"alice","age":30}' | jq '"Name: \(.name), Age: \(.age)"'
# "Name: alice, Age: 30"

# 嵌入复杂表达式
echo '{"first":"alice","last":"smith"}' | jq '"Hello, \(.first | ascii_upcase) \(.last)"'
# "Hello, ALICE smith"

# 构造 URL
echo '{"id":42,"token":"abc123"}' | jq '"https://api.example.com/\(.id)?token=\(.token)"'
# "https://api.example.com/42?token=abc123"

# 配合 -r 输出纯文本
echo '{"name":"alice"}' | jq -r '"Hello \(.name)"'
# Hello alice
```

### 1.7 命令行选项详解

#### `-r` / `--raw-output`

输出原始字符串（不加引号），适合提取值用于 pipe 到其他命令。

```bash
# 不加 -r：带引号的 JSON 字符串
echo '{"name":"alice"}' | jq '.name'
# "alice"

# 加 -r：纯文本
echo '{"name":"alice"}' | jq -r '.name'
# alice

# 实战：提取 IP 地址并 curl
curl -s http://httpbin.org/ip | jq -r '.origin'
# 192.168.1.1
```

#### `-c` / `--compact-output`

紧凑输出（不换行、不缩进），每行一个 JSON 对象。适合 JSONL 格式。

```bash
echo '{"a":1,"b":2}' | jq -c '.'
# {"a":1,"b":2}

# 数组每个元素一行
echo '[{"a":1},{"b":2}]' | jq -c '.[]'
# {"a":1}
# {"b":2}
```

#### `-s` / `--slurp`

把整个输入流（多个 JSON 值或 JSONL）合并成一个数组再处理。

```bash
# 假设有两个文件
echo '{"a":1}' > f1.json
echo '{"b":2}' > f2.json

# 没有 -s：独立处理每个文件
jq '.' f1.json f2.json
# {"a":1}
# {"b":2}

# 有 -s：先合并成数组再处理
jq -s '.' f1.json f2.json
# [{"a":1},{"b":2}]

# 应用：合并配置
jq -s '.[0] * .[1]' base.json override.json
```

#### `--raw-input` / `-R`

把输入按纯文本（每行一个字符串）读取，而不是解析为 JSON。

```bash
# 读取 CSV 或日志文件
echo -e "apple\nbanana\ncherry" | jq -R '.'
# "apple"
# "banana"
# "cherry"

# 配合 -c 和 -s 处理整个文件
echo -e "line1\nline2" | jq -R -s 'split("\n")'
# ["line1","line2",""]

# CSV 解析
echo -e "name,age\nalice,30\nbob,25" | jq -R -c 'split(",")'
# ["name","age"]
# ["alice","30"]
# ["bob","25"]

# 跳过标题行
echo -e "name,age\nalice,30\nbob,25" | jq -R 'split(",")' | jq -s '.[1:]'
```

#### `--arg` 和 `--argjson`

从外部传入变量到过滤器内部。

```bash
# --arg name value：传入字符串
echo '{"items":[1,2,3]}' | jq --arg k "items" '.[$k]'
# [1,2,3]

# 动态过滤
echo '{"users":[{"name":"alice","age":30},{"name":"bob","age":25}]}' \
  | jq --arg min "26" '.users | map(select(.age >= ($min | tonumber)))'
# [{"name":"alice","age":30}]

# --argjson name json：传入 JSON 值
echo '{"config":{"port":8080}}' | jq --argjson override '{"port":9090}' '.config * $override'
# {"port":9090}

# 多个变量
jq -n --arg a "hello" --argjson b '{"key":"val"}' '{$a, b: $b}'
# {"a":"hello","b":{"key":"val"}}
```

#### `-n` / `--null-input`

不读输入，仅用 `--arg` / `--argjson` 的数据构造输出。适合从头生成 JSON。

```bash
jq -n '{name: "test", port: 8080}'
# {"name":"test","port":8080}

jq -n --arg name "alice" --argjson scores '[85,90,92]' '{name: $name, scores: $scores}'
# {"name":"alice","scores":[85,90,92]}
```

#### `-f` / `--from-file`

从文件读取过滤器（过滤器较长时有用）。

```bash
# 写一个过滤器文件
echo '.[] | select(.status == "error") | {msg: .message, time: .timestamp}' > filter.jq

# 使用
curl -s http://api.example.com/logs | jq -f filter.jq
```

#### `-e` / `--exit-status`

根据匹配结果设置退出码。找到匹配时退出码为 0，否则为 1。

```bash
# 在脚本中使用
if echo '{"healthy":true}' | jq -e '.healthy'; then
  echo "Service is healthy"
fi

# 或结合 select 判断
if echo '[1,2,3]' | jq -e 'any(. == 3)'; then
  echo "Found 3"
fi
```

#### 其他实用选项

```bash
# --color-output / --monochrome-output：控制颜色
jq --monochrome-output '.' data.json

# --tab：用 tab 缩进
jq --tab '.' data.json

# --indent n：指定缩进空格数
jq --indent 4 '.' data.json

# -a / --ascii-output：非 ASCII 字符转义为 \uXXXX
echo '"你好"' | jq -a '.'    # "\u4f60\u597d"
```

### 1.8 JSON 与 JSONL 处理差异

JSONL（JSON Lines）每行一个独立 JSON 对象，没有外层的 `[]`。

```bash
# 创建一个 JSONL 文件
echo '{"name":"alice","score":85}' > scores.jsonl
echo '{"name":"bob","score":92}' >> scores.jsonl
echo '{"name":"carol","score":78}' >> scores.jsonl

# 直接遍历
jq '.name' scores.jsonl         # 自动逐行处理
# "alice"
# "bob"
# "carol"

# JSONL 转 JSON 数组（slurp）
jq -s '.' scores.jsonl
# [{"name":"alice","score":85},{"name":"bob","score":92},{"name":"carol","score":78}]

# JSON 数组转 JSONL（-c）
echo '[{"name":"alice"},{"name":"bob"}]' | jq -c '.[]'
# {"name":"alice"}
# {"name":"bob"}

# 流式处理大文件（--stream），避免一次加载整个 JSON
# 适用于非常大的 JSON 数组
jq --stream 'select(.[0] | length == 2) | .[1]' huge.json
```

**关键区别总结**：

| 场景 | JSON 数组 `[{...},{...}]` | JSONL `{...}\n{...}` |
|------|--------------------------|---------------------|
| 遍历元素 | `.[]` | 直接使用过滤器 |
| 合并处理 | 本身就是数组 | `-s` slurp 成数组 |
| 按条件过滤 | `map(select(...))` | `select(...)` |
| 输出为单行 | `-c` 压缩 | `-c` 压缩 |

#### 案例 4：配置合并与覆盖

合并多份配置，实现覆盖逻辑。

```bash
# 基础配置
cat > base.json << 'EOF'
{
  "app": {
    "name": "my-app",
    "port": 8080,
    "log_level": "info",
    "features": {
      "auth": true,
      "metrics": false,
      "debug": false
    }
  },
  "database": {
    "host": "localhost",
    "port": 5432,
    "pool_size": 10
  }
}
EOF

# 环境覆盖（生产环境）
cat > prod.json << 'EOF'
{
  "app": {
    "port": 80,
    "log_level": "warn",
    "features": {
      "debug": false
    }
  },
  "database": {
    "host": "prod-db.example.com",
    "pool_size": 50
  }
}
EOF

# 合并（左侧为基础，右侧覆盖）
jq -s '.[0] * .[1]' base.json prod.json
# {
#   "app": {
#     "name": "my-app",
#     "port": 80,
#     "log_level": "warn",
#     "features": {
#       "auth": true,
#       "metrics": false,
#       "debug": false
#     }
#   },
#   "database": {
#     "host": "prod-db.example.com",
#     "port": 5432,
#     "pool_size": 50
#   }
# }

# 深层合并（递归合并，而不是覆盖整个 features）
# 需要自定义递归合并过滤器
jq -n 'def deep_merge(a; b):
  a as $a | b as $b |
  reduce ($b | keys_unsorted[]) as $k ($a;
    if ($a[$k] | type) == "object" and ($b[$k] | type) == "object"
    then .[$k] = deep_merge($a[$k]; $b[$k])
    else .[$k] = $b[$k]
    end
  );
deep_merge($base; $override)' \
  --argjson base "$(cat base.json)" \
  --argjson override "$(cat prod.json)"
```

#### 案例 5：CSV 提取与格式化

从 JSON 生成 CSV，或从 CSV 提取数据。

```bash
# JSON 转 CSV

# 35,"Shenzhen","carol"

# 用 @csv 和 @tsv 格式化数组为 CSV/TSV

# 3,"c"

bob,25,Shanghai

  map(select(length > 0) | split(",")) |
  .[0] as $headers |
  .[1:] |
  map(
    reduce range(length) as $i ({}; .[$headers[$i]] = .[$i])
  )
'
# [
#   {"name":"alice","age":"30","city":"Beijing"},
#   {"name":"bob","age":"25","city":"Shanghai"}
# ]
```

## 第二章：yq — YAML 处理器

### 2.1 yq 的两大家族

yq 这个名字背后有两个完全不同的项目，这一点经常造成混乱。

| 特性 | Python 版 (kislyuk/yq) | Go 版 (mikefarah/yq) |
|------|----------------------|---------------------|
| 作者 | Andrey Kislyuk | Mike Farah |
| 安装方式 | `pip install yq` | 独立二进制 |
| 依赖 | 需要 jq | 无依赖 |
| 过滤语法 | **完全同 jq** | 自己的语法，类似 jq |
| 性能 | 依赖 jq，略慢 | 原生，较快 |
| 更新频率 | 较慢 | 活跃 |
| `-i` 原地修改 | 支持 | 支持 |
| 多文档处理 | 通过 jq 的 slurp | 原生支持 |
| 谁在用 | 习惯 jq 的用户 | 需要独立工具的场景 |

> **快速判断**：`yq --version` 输出 `yq (https://github.com/kislyuk/yq)` 是 Python 版；输出版本号如 `4.44.0` 是 Go 版。

---

### 2.2 Python 版 yq（kislyuk/yq，依赖 jq）

**核心思路**：先把 YAML 转成 JSON，用 jq 过滤，再把结果转回 YAML。所以你只需要学会 jq，yq 自动就会了。

#### 安装

```bash
# pip 安装（需要已安装 jq）
pip install yq

# macOS（会自动安装 jq）
brew install yq

# 从源码
pip install --upgrade yq
```

#### 基本用法

语法与 jq 完全一致，只是输入输出默认是 YAML。

```bash
# 读取 YAML 字段
cat > deploy.yaml << 'EOF'
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
    env: production
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    spec:
      containers:
        - name: app
          image: my-app:1.0.0
          ports:
            - containerPort: 8080
          env:
            - name: DB_HOST
              value: prod-db.example.com
            - name: LOG_LEVEL
              value: warn
EOF

yq '.metadata.name' deploy.yaml
# "my-app"

yq '.spec.replicas' deploy.yaml
# 3

yq '.spec.template.spec.containers[0].image' deploy.yaml
# "my-app:1.0.0"
```

#### 修改与写回

```bash
# 修改字段（-i 原地写回）
yq -i '.spec.replicas = 5' deploy.yaml

# 修改嵌套字段
yq -i '.spec.template.spec.containers[0].image = "my-app:2.0.0"' deploy.yaml

# 添加字段
yq -i '.spec.template.spec.containers[0].env += [{"name": "DEBUG", "value": "false"}]' deploy.yaml

# 删除字段
yq -i 'del(.spec.template.spec.containers[0].env[-1])' deploy.yaml
```

#### 格式互转

```bash
# YAML -> JSON
yq -o=json . deploy.yaml

# JSON -> YAML
echo '{"name":"test","version":1}' | yq -p=json .

# 格式化 JSON 输入为 YAML
# 当省略 -p 时，yq 根据输入内容自动判断
yq . data.json    # 输出 YAML

# 保持 JSON 输出
yq -o=json . deploy.yaml | jq '.spec'
```

#### 多文档 YAML

Kubernetes、CI 配置文件常包含多个 YAML 文档（用 `---` 分隔）。

```bash
# 创建多文档 YAML
cat > multi.yaml << 'EOF'
apiVersion: v1
kind: Namespace
metadata:
  name: my-namespace
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
---
apiVersion: v1
kind: Service
metadata:
  name: my-app
spec:
  ports:
    - port: 80
EOF

# Python 版 yq 默认逐个文档应用过滤器
yq '.kind' multi.yaml
# "Namespace"
# "Deployment"
# "Service"

# 用 -s（slurp）合并成数组处理
yq -s 'map(.kind)' multi.yaml
# - Namespace
# - Deployment
# - Service

# 筛选特定类型的文档
yq -s '.[] | select(.kind == "Deployment")' multi.yaml
```

### 2.3 Go 版 yq（mikefarah/yq）

Go 版 yq 是独立的 YAML 处理工具，不依赖 jq，功能更全面，但也需要学习自己的语法。

#### 安装

```bash
# macOS
brew install yq

# Linux - 直接下载二进制
wget https://github.com/mikefarah/yq/releases/latest/download/yq_linux_amd64 -O /usr/local/bin/yq
chmod +x /usr/local/bin/yq

# 或使用 snap
snap install yq

# Windows
scoop install yq
# 或
winget install yq

# Docker
docker run --rm -v "$PWD":/workdir mikefarah/yq yq '.spec.replicas' deploy.yaml

# 验证
yq --version
# yq (https://github.com/mikefarah/yq/) version v4.44.0
```

#### 基本语法

Go 版 yq 的语法**类似 jq 但不完全相同**。以下是常见操作：

```bash
# 读取字段
yq '.spec.replicas' deploy.yaml

# 类似 jq，但不支持逗号多表达式，需要用 with 或 ireduce
# .key1.key2 嵌套读取
yq '.spec.template.spec.containers[0].image' deploy.yaml

# 数组索引
yq '.spec.template.spec.containers[0].ports[0].containerPort' deploy.yaml

# 数组遍历
yq '.spec.template.spec.containers[].name' deploy.yaml

# 条件过滤
yq '.[] | select(.kind == "Deployment")' multi.yaml
```

#### 与 Python 版 yq 的语法差异

| 操作 | Python 版（同 jq） | Go 版 |
|------|-------------------|-------|
| 原地修改 | `yq -i '.x = 1' f.yaml` | `yq -i '.x = 1' f.yaml` |
| 删除 | `del(.x)` | `del(.x)` 或 `yq eval 'del(.x)'` |
| 指定输出格式 | `-o=json` | `-o=json` |
| 多个表达式 | 逗号 `.name, .age` | 用 `eval-all` |
| 环境变量引用 | `env.VAR` | `env(VAR)` |
| 空值合并 | `//` | `//` |
| 长度 | `length` | `length` |
| 字符串插值 | `"\(.x)"` | `"\(.x)"` |

#### 常用操作详解

```bash
# 读取所有字段
yq '.' deploy.yaml

# 修改字符串
yq -i '.spec.template.spec.containers[0].image = "nginx:latest"' deploy.yaml

# 修改数字
yq -i '.spec.replicas = 5' deploy.yaml

# 数组追加
yq -i '.spec.template.spec.containers[0].ports += [{"containerPort": 9090}]' deploy.yaml

# 删除数组元素
yq -i 'del(.spec.template.spec.containers[0].ports[1])' deploy.yaml

# 添加注释（Go 版特有功能）
yq -i '.spec.replicas headComment = "Number of application replicas"' deploy.yaml

# 查看节点路径
yq '.spec.replicas | path' deploy.yaml
```

#### 多文档 YAML 处理

Go 版 yq 对多文档有原生支持。

```bash
# 提取所有文档的 kind
yq '.kind' multi.yaml

# 筛选特定文档
yq 'select(.kind == "Deployment")' multi.yaml

# 多文档合并
yq eval-all 'select(fileIndex == 0) * select(fileIndex == 1)' base.yaml override.yaml

# 按文档索引操作
yq 'select(di == 0)' multi.yaml     # 第一个文档
yq 'select(di == 1)' multi.yaml     # 第二个文档

# 拆分多文档
yq eval-all '. | select(di == 0)' multi.yaml > part1.yaml
```

#### 格式互转

```bash
# YAML -> JSON
yq -o=json '.' deploy.yaml

# JSON -> YAML
cat data.json | yq -P '.'     # -P = pretty print

# YAML -> 属性文件（key=value 格式）
yq -o=props '.' deploy.yaml
```

```bash
yq eval-all '. as $item ireduce ({}; . * $item)' configmap.yaml secret.yaml
```

## 第三章：总结对比与学习路径

### 3.1 完整对比

| 特性 | jq | Python yq (kislyuk/yq) | Go yq (mikefarah/yq) |
|------|-----|----------------------|---------------------|
| 处理格式 | JSON | YAML (可处理 JSON) | YAML (可处理 JSON) |
| 语法 | 自己的 DSL | 同 jq | 类似 jq，有差异 |
| 安装体积 | ~1MB | 需 Python + jq | ~10MB 单文件 |
| 依赖 | 无 | jq | 无 |
| 原地修改 `-i` | 支持 | 支持 | 支持 |
| 多文档 YAML | 不支持 | 通过 `-s` 模拟 | 原生支持 |
| YAML 注释保留 | 不适用 | 会丢失 | 保留 |
| 性能 | 极快 | 中等（JSON 中转） | 快 |
| Windows 支持 | 好 | 好（需 Python） | 好 |
| 学习成本 | 中 | 零（会 jq 即会） | 低（类似 jq） |

### 3.2 学习路径建议

按场景选择合适的路径：

**路径 A：后端开发者（处理 API 数据为主）**

1. 先掌握 jq 基础：`.` `.[]` `|` `select()` `map()`
2. 再学对象构造 `{...}` 和字符串插值
3. 然后学 `--arg` 和 pipeline 组合
4. 最后掌握 `-r` `-c` `-s` 等选项

**路径 B：DevOps / SRE（处理 K8s 和 CI 配置为主）**

1. 先学 Python 版 yq（因为会 jq 就会了）
2. 同时学 jq 基础，与 yq 通用
3. 然后学 Go 版 yq 的独特功能（注释保留、多文档原生支持）
4. 跟 jq 混用，处理 JSON 用 jq，YAML 用 yq

**路径 C：两者都需要**

1. 集中精力学好 jq（投入产出比最高）
2. Python 版 yq 不需要额外学习
3. 在需要注释保留或复杂多文档操作时切换到 Go 版 yq
4. 记住两个版本的语法差异对照表

### 3.4 常见问题与技巧

**Q: 我的 yq 不支持某些语法？**
A: 先确认是哪个版本。`yq --version` 看输出。Python 版语法同 jq，Go 版需要看对应文档。

**Q: jq 处理大文件太慢怎么办？**
A: 使用 `--stream` 流式模式，避免将整个 JSON 加载到内存。
```bash
jq --stream 'select(.[0] | length == 2) | .[1]' huge-file.json
```

**Q: 如何在 jq 中做分组统计？**
A: 结合 `group_by` 和 `length`：
```bash
jq -s 'group_by(.category) | map({category: .[0].category, count: length, items: [.[].name]})'
```

**Q: jq 如何在 Windows 上处理中文文件名？**
A: 确保 PowerShell 使用 UTF-8 编码：
```powershell
$OutputEncoding = [Console]::OutputEncoding = [Text.UTF8Encoding]::UTF8
jq '.' file.json
```

**Q: 如何在 jq 中做循环/递归？**
A: jq 支持递归函数定义：
```bash
jq 'def walk(f): . as $in | if type == "object" then with_entries(f) | map_values(walk(f)) elif type == "array" then map(walk(f)) else . end; walk(.)'
```

**Q: 如何格式化但不经过 . 过滤器？**
A: 直接用 jq 不传过滤器：
```bash
jq '' file.json    # 等价于 jq '.' file.json
```
