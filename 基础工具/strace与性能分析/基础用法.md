`strace` 是 Linux 的系统调用跟踪器。它拦截并记录进程发起的**所有系统调用**（syscall）及其返回值，比如 `open`、`read`、`write`、`ioctl` 等。

**典型用法**：

```bash
# 跟踪命令
strace ls

# 跟踪已运行的进程
strace -p <PID>

# 只跟踪特定 syscall（减少噪音）
strace -e trace=open,read,write ls

# 显示时间戳/耗时
strace -tt -T ls

# 统计各 syscall 次数/耗时
strace -c ls
```

**常用场景**：
- 程序启动失败但没报错 → 看 `open` 了哪些文件、返回了什么 errno
- 性能瓶颈 → `-T` 看哪个 syscall 耗时最长，`-c` 看调用频率
- 配置文件没生效 → 确认进程实际读取了哪个路径
- 无权限排查 → 看 `open` 返回 `EACCES` / `EPERM`

**注意事项**：输出量极大，一定要用 `-e trace=` 过滤，或用 `-o file` 写文件后再分析。
