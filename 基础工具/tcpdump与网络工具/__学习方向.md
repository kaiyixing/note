# tcpdump 与网络工具 — 学习方向

## 核心工具
| 工具 | 用途 |
|------|------|
| `tcpdump` | 抓包分析网络流量 |
| `ss` | 查看 socket 统计（替代 netstat） |
| `nc` (netcat) | 端口探测、TCP/UDP 测试 |
| `nslookup` / `dig` | DNS 查询 |
| `curl` | HTTP 请求调试 |
| `mtr` | 路由追踪 + ping 结合 |
| `nmap` | 端口扫描 |

## 实操清单
- [ ] `tcpdump -i eth0 port 80` 抓 HTTP 包
- [ ] `tcpdump -w file.pcap` 保存后用 Wireshark 分析
- [ ] `ss -tuln` 查看监听端口
- [ ] `nc -zv 192.168.1.1 22` 测试端口连通性
- [ ] `dig example.com` DNS 解析排查
- [ ] `curl -v http://api.example.com` 调试接口

## 常见场景
- 排查"端口不通"（iptables 问题 vs 服务未启动）
- 接口返回慢，抓包看耗时在哪里
- 检查 DNS 解析有没有被劫持
- 排查 TCP 连接数过多（TIME_WAIT 堆积）
