# tmux — 学习方向

## 核心概念
- **Session**：会话（一个工作区，可后台保持）
- **Window**：窗口（Session 内的标签页）
- **Pane**：窗格（Window 内的分割区域）
- **前缀键**：默认 `Ctrl-b`，所有快捷键的前置

## 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl-b %` | 垂直分割窗格 |
| `Ctrl-b "` | 水平分割窗格 |
| `Ctrl-b 方向键` | 切换窗格 |
| `Ctrl-b c` | 新建窗口 |
| `Ctrl-b 数字` | 切换到第 N 个窗口 |
| `Ctrl-b d` | 脱离会话（detach） |
| `Ctrl-b [` | 进入滚动模式（翻看历史输出） |

## 实操清单
- [ ] `tmux new -s work` 创建会话
- [ ] `tmux attach -t work` 重新连接
- [ ] `tmux ls` 查看会话列表
- [ ] 配置 `.tmux.conf`（修改前缀键、颜色等）
- [ ] 结合 Vim/Neovim 使用（一个 pane 编辑器，一个 pane 运行）

## 核心用途
- SSH 连接断了，工作不会丢（detach/attach）
- 服务器上长时间任务（编译、数据迁移）不会中断
- 一个终端里同时看代码 + 运行日志
