# Vim/Neovim 高频操作速查

> 只记最常用的，其他用到再查。

---

## 生存三件套

| 操作 | 命令 |
|------|------|
| 保存 | `:w` |
| 退出 | `:q` |
| 强制退出（不保存） | `:q!` |
| 保存并退出 | `:wq` 或 `ZZ` |

---

## 移动

```
h ←    j ↓    k ↑    l →
w     跳到下一词首       b     跳到词首
0     行首               $     行尾
gg    文件开头            G     文件末尾
Ctrl-d  向下翻半页       Ctrl-u  向上翻半页
%     跳到匹配括号
```

---

## 编辑

| 操作 | 命令 |
|------|------|
| 光标前插入 | `i` |
| 行尾插入 | `A` |
| 下方新行插入 | `o` |
| 删除光标字符 | `x` |
| 删除一行 | `dd` |
| 复制一行 | `yy` |
| 粘贴 | `p` |
| 撤销 | `u` |
| 重做 | `Ctrl-r` |
| 重复上次操作 | `.` |

---

## 选择（可视模式）

```
v       按字符选择
V       按行选择
Ctrl-v  矩形块选择
```

选中后按 `d` 删除、`y` 复制、`>` 缩进。

---

## 文本对象（核心效率）

```
ciw   删除光标所在单词并修改
ci"   删除引号内内容并修改
ci(   删除括号内内容并修改
da"   删除包括引号在内的内容
```

> `c` = 修改  `d` = 删除  `y` = 复制
> `i` = 内部  `a` = 包括包围字符

---

## 搜索与替换

```vim
/关键词    搜索（n 下一个，N 上一个）
*          搜索光标下的词
:%s/旧/新/g    全局替换
```

---

## 窗口

```vim
:sp [file]     水平分割
:vs [file]     垂直分割
Ctrl-w h/j/k/l  在窗口间移动
```

---

## 必备配置

```lua
-- ~/.config/nvim/init.lua
vim.opt.clipboard = "unnamedplus"   -- 让 y 复制到系统剪贴板
vim.opt.number = true               -- 显示行号
vim.opt.relativenumber = true       -- 相对行号
vim.opt.tabstop = 4
vim.opt.shiftwidth = 4
vim.opt.expandtab = true            -- 空格代替 Tab
```

---

## 一句话原则

**大部分时间待在 Normal 模式**，进 Insert 只打字，打完立刻 `Esc` 返回。
