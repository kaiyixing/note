# Kafka — 学习方向

## 核心概念
- **Topic**：消息主题（逻辑分类）
- **Partition**：分区（物理分片，顺序写 + 并行读）
- **Producer**：生产者（发送消息）
- **Consumer / Consumer Group**：消费者（组内负载均衡）
- **Broker**：Kafka 服务节点
- **Offset**：消息在分区内的位置
- **ISR**（In-Sync Replica）：同步副本集
- **ZooKeeper / KRaft**：元数据管理

## 学习路径
1. 先搭起来，跑通生产消费
2. 理解 Partition 的作用和 Kafka 为什么快
3. 学习 Consumer Group 的多消费者并行消费
4. 深入可靠性和一致性配置
5. 集群部署与监控

## 常见场景
- 日志采集（Flume / Filebeat → Kafka → ELK）
- 异步解耦（订单系统 → 消息 → 通知/积分/物流）
- 流处理（Kafka Streams / Flink 消费 Kafka）
