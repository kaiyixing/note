# PostgreSQL — 学习方向

## 核心概念
- **MVCC**：多版本并发控制（与 MySQL InnoDB 实现不同）
- **WAL**（Write-Ahead Log）：预写日志
- **索引类型**：B-Tree、Hash、GiST、GIN、BRIN
- **VACUUM**：清理死元组（autovacuum）
- **TOAST**：大字段存储优化
- **扩展生态**：PostGIS（地理空间）、TimescaleDB（时序）、pgvector（向量）

## 实操清单
- [ ] 安装 PostgreSQL + `psql` 命令行熟练使用
- [ ] 数据库/表/索引创建与管理
- [ ] `pg_config`、`pg_hba.conf`、`postgresql.conf` 配置
- [ ] 备份恢复：`pg_dump`、`pg_restore`、`pg_basebackup`
- [ ] 主从复制：流复制 + 同步/异步模式
- [ ] `EXPLAIN ANALYZE` 看执行计划
- [ ] VACUUM 和 autovacuum 配置优化
- [ ] JSONB 数据类型使用

## 学习路径
1. 基本 CRUD + psql 操作
2. 高级特性：CTE、窗口函数、JSONB
3. 索引优化和执行计划
4. 复制、备份、高可用

## 常见场景
- 复杂分析查询（窗口函数、CTE）
- JSON 数据存储（比 MySQL 的 JSON 好用）
- 地理空间查询（PostGIS）
- 时序数据（TimescaleDB 扩展）
