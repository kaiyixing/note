# ETCD — 学习方向

## 核心概念
- **分布式 KV 存储**：强一致性、高可用
- **Raft 共识算法**：Leader 选举、日志复制
- **Watch 机制**：客户端监听 key 变更
- **TTL / Lease**：键值对自动过期
- **MVCC**：多版本并发控制

## 主要用途
- **Kubernetes** 的集群状态存储（所有资源数据）
- **服务发现**与配置中心
- **分布式锁**实现

## 实操清单
- [ ] 部署单机 ETCD（`etcd` + `etcdctl`）
- [ ] `etcdctl put/get/del` 基本 CRUD
- [ ] `etcdctl watch` 监听 key 变化
- [ ] `etcdctl lease grant` + `put --lease` 实现 TTL
- [ ] 部署 3 节点 ETCD 集群
- [ ] 集群备份与恢复（`etcdctl snapshot`）
- [ ] ETCD 性能调优（存储限制、碎片整理）

## 常见场景
- Kubernetes 集群 ETCD 备份恢复
- ETCD 空间满导致集群不可用（`--auto-compaction`）
- 分布式锁实现（`concurrency/stm`）
