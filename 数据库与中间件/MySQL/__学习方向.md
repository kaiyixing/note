# MySQL — 学习方向

## 核心概念
- **InnoDB 存储引擎**：事务、行锁、MVCC、聚簇索引
- **索引**：B+ Tree、聚簇索引、二级索引、联合索引
- **事务**：ACID、隔离级别（RU/RC/RR/SERIALIZABLE）
- **锁**：行锁、间隙锁（Gap Lock）、Next-Key Lock、意向锁
- **Redo Log / Undo Log / Binlog**：三种日志的作用
- **主从复制**：异步复制、半同步复制、GTID

## 实操清单
- [ ] 数据库建表、索引优化（`EXPLAIN` 分析）
- [ ] 慢查询日志开启与分析
- [ ] 事务隔离级别验证（`SELECT @@tx_isolation`）
- [ ] 死锁排查（`SHOW ENGINE INNODB STATUS`）
- [ ] 主从搭建（`CHANGE MASTER TO`）
- [ ] 备份恢复（`mysqldump`、`xtrabackup`）
- [ ] 数据迁移（`pt-online-schema-change` 在线改表）

## 学习路径
1. 日常 CRUD + 索引优化（EXPLAIN 看懂）
2. 理解事务和锁（常见死锁场景）
3. 复制、备份、高可用（MHA / Orchestrator）
4. 性能调优（参数、硬件、架构）

## 常见场景
- 查询慢 -> 加索引 / 改写 SQL
- 死锁 -> 调整 SQL 顺序 / 降低隔离级别
- 主从延迟 -> 检查大事务 / 从库写入压力
- 数据误删 -> binlog 闪回恢复
