# RabbitMQ — 学习方向

## 核心概念
- **Producer / Consumer**：生产者 / 消费者
- **Queue**：消息队列（FIFO）
- **Exchange**：交换机（决定消息到哪个队列）
- **Routing Key / Binding Key**：路由规则
- **Exchange 类型**：Direct、Topic、Fanout、Headers
- **ACK**：消息确认（手动 ACK vs 自动 ACK）
- **死信队列**（DLQ）：处理失败消息

## 常用模式
| 模式 | Exchange 类型 | 场景 |
|------|---------------|------|
| 点对点 | Direct | 一个生产者一个消费者 |
| 发布订阅 | Fanout | 广播消息给所有消费者 |
| 路由分发 | Topic | 按路由规则选择性消费 |
| RPC | Direct + ReplyTo | 远程调用 |
