# 测试 — 学习方向

## 学习路径
这个目录放在 `assets/` 下，如果是测试相关文档，建议迁移到更合适的位置或明确分类。

可能的用途：
- 测试用的占位文件 / 临时文件
- 测试脚本（shell、Python 等）
- 学习笔记中的测试用例

如需系统学习软件测试，参考以下方向：

| 类型 | 说明 | 工具 |
|------|------|------|
| **单元测试** | 函数/方法级别 | pytest、JUnit、go test |
| **接口测试** | HTTP API 测试 | Postman、curl、httpx |
| **压力测试** | 并发/性能测试 | wrk、hey、JMeter |
| **集成测试** | 多模块协作测试 | docker-compose + test |
| **端到端测试** | 用户场景模拟 | Selenium、Playwright |
