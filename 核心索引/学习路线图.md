## 🔗 推荐学习路径

```
入门期（1-3 月）：
  Linux 操作 → Git/Vim/tmux → Shell 脚本 → Docker → K8s 基础

进阶期（3-6 月）：
  网络（TCP/IP/DNS/负载均衡）→ Prometheus + Grafana → MySQL/Redis → Ansible

深入期（6-12 月）：
  Ceph/NFS 存储 → ELK/Loki 日志 → K8s 进阶（Helm/Operator/CI/CD）→ 告警管理

面试期：
  算法刷题 + 系统设计 + 面经复习 + 项目复盘
```
