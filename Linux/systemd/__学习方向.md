# systemd — 学习方向

## 核心概念
- **unit 类型**：service、timer、socket、path、target
- **unit 文件结构**：`[Unit]`、`[Service]`、`[Install]` 各段含义
- **target**：取代 SysV init 的运行级别（multi-user.target 等）
- **journald**：日志系统（`journalctl`）

## 实操清单
- [ ] `systemctl start/stop/restart/enable/disable/status`
- [ ] 编写一个自定义 .service 文件
- [ ] `journalctl -u nginx -f` 查看服务日志
- [ ] `systemd-analyze blame` 分析开机耗时
- [ ] Timer 替代 cron 定时任务
- [ ] `systemctl daemon-reload` 重载配置

## 常见场景
- 写一个开机自启的 Java/Python 服务
- 服务崩溃自动重启（`Restart=always`）
- 用 Timer 实现定期日志清理
