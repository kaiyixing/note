# Linux 权限管理 — 学习方向

## 核心概念
- **UGO 模型**：User（所有者）、Group（组）、Other（其他人）
- **rwx 权限**：读（4）、写（2）、执行（1）
- **特殊权限**：SUID (4xxx)、SGID (2xxx)、Sticky Bit (1xxx)
- **ACL**：更细粒度的权限控制（`setfacl` / `getfacl`）
- **umask**：默认权限掩码

## 实操清单
- [ ] `chmod`、`chown`、`chgrp` 熟练使用
- [ ] SUID/SGID/Sticky Bit 各自作用与场景
- [ ] ACL 实现给特定用户授权
- [ ] `sudoers` 配置（`visudo`）

## 常见场景
- 网站目录权限设置（755/644 原则）
- 多用户协作组权限设计
- 限制普通用户执行特定命令（sudo）
