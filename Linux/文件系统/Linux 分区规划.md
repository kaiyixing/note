# Linux 分区规划

Linux 分区没有"官方标准"，实际是**功能导向**的规划。按使用场景分两大类：**引导型** 和 **数据型**。

## 一、引导型分区（系统启动必需）

### 1. `/boot`
| 项目 | 说明 |
|------|------|
| 大小 | 1~4GB |
| 用途 | 存放内核（vmlinuz）、initramfs、GRUB 配置、启动脚本 |
| 为什么单独分 | 根分区写满不影响开机；备份恢复也方便（`dd` 备份整个 /boot） |

### 2. EFI 系统分区（ESP）
| 项目 | 说明 |
|------|------|
| 大小 | 100MB~500MB |
| 格式 | **必须 FAT32**，UEFI 固件只认这个 |
| 用途 | 存 EFI 引导文件（`grubx64.efi`、`bootx64.efi`） |
| 挂载点 | `/boot/efi` 或 `/boot/EFI` |

### 3. `/boot/loader`（较新发行版）
| 项目 | 说明 |
|------|------|
| 大小 | 512MB~1GB |
| 用途 | systemd-boot 或 grub 的 EFI 引导加载器 |

## 二、数据型分区（业务运行）

### 4. `/`（根分区）
| 项目 | 说明 |
|------|------|
| 大小 | 20~50GB（服务器建议 40GB+） |
| 用途 | 系统文件、二进制、`/etc`、`/usr`、`/opt` |
| 注意 | 尽量不写满，否则系统卡死 |

### 5. `/home`
| 项目 | 说明 |
|------|------|
| 大小 | 按需，几十 GB 到 TB 级 |
| 用途 | 用户个人数据、项目文件 |
| 为什么单独分 | 重装系统不丢数据；多用户隔离 |

### 6. `/var`
| 项目 | 说明 |
|------|------|
| 大小 | 按需，日志大户给 20GB+ |
| 用途 | 日志（`/var/log`）、数据库、缓存、运行数据 |
| 为什么单独分 | `/var/log` 和 `/var/lib` 增长极快，把根分区撑爆是常见故障 |

### 7. `/tmp`
| 项目 | 说明 |
|------|------|
| 大小 | 2~5GB |
| 用途 | 临时文件、编译中间产物 |
| 说明 | 现代发行版通常用 **tmpfs**（放内存），重启清空，不用真分区 |

### 8. `/opt`
| 项目 | 说明 |
|------|------|
| 大小 | 按需 |
| 用途 | 第三方软件、商业软件（Oracle、VMware） |

### 9. `/srv`
| 项目 | 说明 |
|------|------|
| 大小 | 按需 |
| 用途 | 服务数据（Nginx、MySQL、Samba 共享） |

### 10. `/usr/local`
| 项目 | 说明 |
|------|------|
| 大小 | 按需 |
| 用途 | 手动编译安装的软件、本地应用 |

## 三、特殊用途

### 11. swap
| 项目 | 说明 |
|------|------|
| 大小 | 内存 1~2 倍（16GB+ 内存可不设） |
| 用途 | 内存不足时做虚拟内存，防 OOM |
| 注意 | 现代系统建议用 swap 文件（`fallocate` 创建）而非分区 |

### 12. LVM 物理卷
| 项目 | 说明 |
|------|------|
| 用途 | 做逻辑卷（LV），可动态扩缩容 |
| 适合 | 数据库、日志等增长不可预测的场景 |

## 四、典型服务器分区方案

```
磁盘 500GB：
├── /boot/efi    1GB     ESP
├── /boot        2GB     内核+GRUB
├── /            40GB    系统
├── /var         80GB    日志+数据
├── /home        剩余     用户数据
└── swap         4~8GB   按需
```

## 五、核心原则

- **系统区（/、/boot、/var、/home）分开** → 日志写满不拖垮系统
- **数据区独立** → 备份/恢复只备份数据，不重装系统
- **LVM 优先** → 动态扩缩比固定分区灵活
- **tmp 用 tmpfs** → 不占磁盘，重启清空

## 六、查看与工具

```bash
lsblk                       # 看磁盘/分区结构
fdisk -l /dev/sda          # 看分区表
parted /dev/sda print     # 看 GPT 分区
blkid                       # 看分区 UUID 和文件系统
df -h                      # 看挂载和使用率
mount | grep sda           # 看挂载点
```
