# Linux 文件系统 — 学习方向

## 核心概念
- **目录结构**：`/`、`/etc`、`/var`、`/usr`、`/proc`、`/sys` 各自用途
- **文件类型**：普通文件、目录、链接、设备文件、socket、pipe
- **软链接 vs 硬链接**：inode 理解是关键
- **文件系统类型**：ext4、XFS、Btrfs、ZFS 的对比与选型
- **挂载与管理**：`mount`、`umount`、`fstab`、`df`、`du`

## 实操清单
- [ ] `ln -s` 创建软链接，`ln` 创建硬链接
- [ ] `df -h`、`du -sh *` 查看磁盘使用
- [ ] `fdisk` / `parted` 分区
- [ ] `mkfs.ext4` 格式化
- [ ] `mount` 挂载 & `/etc/fstab` 开机自动挂载
- [ ] `lsof` + `fuser` 处理"设备正忙"
- [ ] `inode` 耗尽问题排查

## 常见场景
- 磁盘满了，大文件查找与清理
- 软链接断裂（broken symlink）排查
- 新增磁盘挂载到指定目录
